## 2. 分类的具体定义缺口

原C0已比较教师与冻结RGB参考，不是只看教师可靠。选择分数为：

`q = [softplus(-e_R) - softplus(-e_T)]_+`

其中e是GT类框内相对外围背景的log-mean-exp logit差，经温度和跨尺度平均。教师正确性另由候选门判定。C1完整保留此选择，却传递每个有效尺度的全部类别相对logits。

因此，正确类的平均相对证据占优，不能认证每个尺度、每个非GT类的教师内容也更好。源码并非把非GT置零；它只是匹配教师。不能未经数据验证就说这部分正在产生负迁移。

还需区分相对背景证据和单对象类别概率。`region_masks`前景包含GT框内所有位置，没有排除其他GT；背景才排除全部GT。重叠比例只是记录。`delta_c=LME_FG(z_c)-LME_BG(z_c)`可以在多个类别都为正，不能因GT为y就要求所有非y的delta小于零。前景重叠率也不是异类污染率。

已排除的草率改法：直接用非GT相对logit的softplus当负标签风险筛选或压低。该方案隐含未经支持的监督语义，独立审阅在核区域后撤回。

**更贴近Drone瓶颈的候选问题：教师是否真的更能区分当前对象的GT类别和RGB最混淆的类别？** 可研究由冻结R确定一个混淆类别，在有唯一对象归属的支持位置上比较GT-vs-confuser的类别margin，再迁移教师相对有利的区分信息。使用前景类间差，而不是把所有前景相对背景响应当作互斥类别概率。

这仍需明确支持位置、跨模态对应与分数尺度。已保存C1汇总缺逐对象/尺度/类别raw，不能由全批均值推算多少非GT项有害；当前没有新训练或有效性结论。不得直接把margin或条件选择宣称为原创，后续还需核最近文献。

## 3. 定位的具体表示缺口

L2与L3的教师来源不同：

- L2在教师合法候选中按GT IoU优先选点，再只传期望框；30次选择只有1次与R同anchor。其教师点不是保证等于native NMS匹配点，首批7个都不同。
- L3硬编码教师与R同anchor，传完整DFL。这是当前实际短训路径。
- 原CPU跨anchor压力接口另测试native教师点→R点：78对中63对因支撑范围拒绝，15对接受且全为恒等。**这不是L3实际训练丢了63/78对象；它说明该接口限制了另一个教师来源，L3主动使用同anchor绕开了它。**

运输规则要求softmax的16个bin都严格正，任一正质量映射到学生0–15支撑之外即整对象拒绝。LLVIP共享GT时，教师/学生中心不同，会令左/右或上/下至少一边源0-bin映射为负。拒绝可以由表示规则触发，不能当成教师预测质量不足的证据；也不能尚未计算就断言越界全是可忽略尾部。

GT坐标映射为恒等仅表示共享标签下没有新几何修正，不证明像素物理配准。DFL的GT两bin分布本身已有方差f(1−f)，f为距离小数部分；非零宽度不自动成为教师额外的不确定性知识。

**值得保留的候选是对象边界证据：教师在自己的可靠检测点产生目标，学生在自己的学习位置接收，双方在公共对象边界坐标比较。** 若采用累积分布距离等允许不同支撑的表达，应新立身份，完整保留概率且注明坐标假设，不能静默clamp/重归一后沿用L1/L3名称。此处没有擅自选择新损失、改变门或发布新训练配置。

完整分布若要声称超出四坐标，须与“相同教师均值、仅邻近两bin目标”区分，GT控制只能回答是否超出额外GT监督，不能隔离分布形状贡献。

证据：[L2来源](../2026-09-08_probe_定位学习位置与目标/FINAL_REPORT.md)、[L3源码](../2026-09-08_probe_对象坐标分布目标/trainer_release/l3_distribution_loss.py)、[运输规则](../2026-09-08_probe_对象坐标分布目标/transport/probability_transport.py)、[原78对结果](../2026-09-08_probe_对象坐标分布目标/transport/output_attempt1/summary.json)。新增缓存复算如完成，由独立的`2026-09-09_probe_已有分布内容复核`条目提供。

### 本轮实际补算后的约束

仅用原缓存已完成[越界质量与分布内容复核](../2026-09-09_probe_已有分布内容复核/README.md)，没有新前向。原63个拒绝对象在T=2下的最大单边越界质量中位0.6174%、P95 5.5932%、最大49.1806%；44/63对象最大边≤1%，说明有不少小质量尾部拒绝，但不能全部直接截断放行。

更关键的反证也应保留：77个共同合法对象上，native教师点/同R教师点的平均像素误差2.3009/2.3165，按对象宽高归一误差0.0366695/0.0360676，没有明显的native点均值优势。因此支撑限制虽真实，**不能仅凭它就认定改取native教师点会扩大收益**。公共坐标表达是一个可讨论的接口修正，不是当前已经胜出的方法。

温度2下宽度显著增大属于已测分布描述；在当前恒等、师生同温度KL中，学生复制教师logits仍可保留教师原生T=1位置，不能把软化均值变化误诊为定位最优解错误。新probe的数值独立审阅另见其REVIEW。

## 4. 方法工作如何收敛

定位的数据动机仍优先LLVIP；Drone分类保留C0已学出的小幅收益作为起点，针对类间区分。两个数据集不应强行共用一个没有语义区别的全logit KL。分类与定位不叠加成新联合方法，局部特征不因信息量更大就自动优先。

下一项实现须能回答一个具体变化的作用：分类从前景/背景证据转向明确类别区分，或定位从同anchor目标转向对象边界坐标中的独立教师内容。冻结实现与对应控制后再用完整训练判断，不能继续用成熟FT3或失效子集排名淘汰方向。

训练底座复用已批量化的快速实现、原数据/E200/native损失和同版本基线；不通过改学生、输入尺寸、训练人口或评价分母换取漂亮结果。既有三seed/四臂规范保留。完整≤10小时仍需端到端验证，不把短窗外推宣称达标。

文献仅提供机制背景：CrossKD明确讨论学生原生监督与教师预测的冲突，并提出跨头路径；其COCO结果不证明我们的跨模态场景有效，也不授权当前改为CrossKD。[作者论文](https://openaccess.thecvf.com/content/CVPR2024/html/Wang_CrossKD_Cross-Head_Knowledge_Distillation_for_Object_Detection_CVPR_2024_paper.html)
