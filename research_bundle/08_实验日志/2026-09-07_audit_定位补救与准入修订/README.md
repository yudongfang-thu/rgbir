# 定位补救与准入修订建议（2026-09-07）

**定位仍值得补救：现有阻塞是原L1几何证据准入未达成，没有定位长训负结果。建议先补目标稳健性诊断，再制定独立的“对象身份＋定位目标质量”准入版本，暂称L2；不在原L1名下放宽规则。**

## 目的与执行范围

回应用户“定位这部分怎么处理，还能补救吗”。主代理核对本地审计、旧D2完整selected字段和两幅无框面板；两个独立审阅分别检查事实与方案边界。使用research-lit检索原论文资料。仅分析与候选方案，没有修改冻结trainer、L1合同、阈值、配置或在跑任务，没有新GPU诊断、长训或增益数字。

## 为什么应考虑修订准入

P3 stride8对应原规则P95最多2输入像素，目标短边10像素时进一步变为1像素。Drone约48%的旧selected来自small目标，IR边缘模糊和视差会使六点跨三象限、覆盖对象及边界邻域的人工证明代价很高。P4不能绕过短边项。

六物理点与跨三象限是原L1冻结合同的要求，不是所有检测输出蒸馏的数学必要条件。输出目标的必要问题是：对象身份是否可靠、目标的坐标/距离含义是否一致、它在学生RGB标签坐标下是否有可利用质量。这个研究判断允许提出新合同，但不能回头把原L1标为已通过，也不构成像素级配准证明。

## 建议的最小补救顺序

1. **核对raw缓存并冻结诊断。** 本地完整D2 selected行确实没有T/R decoded boxes和raw DFL，见[字段清单](local_payload_inventory.json)。先查服务器已有缓存；没有则从既定train流一次小规模、共享lease的导出，保留GT/对象身份/全部候选归属/anchor/stride/增强矩阵/基础分母/全部过滤步骤。不能从IoU和熵反推假分布。
2. **测任务目标的稳健性。** 固定对象、anchor、掩码和分母，分别检查无扰动及预先固定的1/2/4输入像素几何扰动下，教师RGB-GT定位优势、DFL目标差异及检测头局部梯度。另表记录门控存活，不能重选对象掩盖脆弱性。扰动是压力测试，不证明实际残差范围；局部logit梯度不是完整native/特征模块校准。
3. **原合同只做有限精审。** 若继续原L1，可优先Drone03429/10789、LLVIP050067/060109原图精细标点，观察是否真的能覆盖对象而非仅场景角落。有通过再扩到固定流候选38张Drone/35张LLVIP；不重新抽64批。没有通过则保留UNKNOWN，避免盲目审核上百图。
4. **优先准备单独L2：对象身份＋目标质量准入。** 先保留单分支、固定R粗候选、唯一归属、0.70任务门及DFL载体。统一画布、anchor/stride/bin语义必须明确；教师目标在RGB GT下直接核验，不能仅以其对IR标签更好或置信度高放行。DFL内容质量、对应不确定性和原生监督冲突必须一起报告。新合同不要求把所有对象先证明为像素精确同物理点，但也不宣称已经解决配准。
5. **新版本先完整冻结再训练。** 明确是否加入额外DFL质量筛选、固定掩码和分母、真实增强后的有效覆盖及校准规则。保留原≥16非零批/≥16唯一图/≥2来源要求，复核同掩码GT控制；所有新路径重新canary。只有正式独立审阅和准入完成，才安排L2与L2_GT的seed42 pilot，不借原L1的未完成准入放行，也不改变正在训练的C1。

这是一份候选修订建议，不是L2已冻结、已准入或已启动的回执。首选仍检查Drone；LLVIP同步看训练覆盖，旧dev20.37%不能成为切换或预期收益的依据。

## 为什么不先换ROI、box loss或局部特征

- 不同anchor/stride/ROI的DFL bin不是同一含义，不能未经坐标变换直接KL。
- 以各自预测框归一化会把两个框都变成单位框，抹掉绝对定位信息。
- 用RGB/IR GT构造仿射映射，相当于“RGB GT＋缩放后的教师IR-GT残差”；GT已提供位置/尺度，需同映射同掩码GT控制，不能将改善全称IR定位信息。
- GT锚定的教师分布形状可以另试，但主张变为软目标形状是否有用，DFL熵也不是未经验证即可使用的校准不确定性。
- 局部特征会重新引入区域对应和纹理差异，带宽增加不能自动解决当前目标可用性问题。
