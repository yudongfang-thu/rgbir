# 小时级筛选：优先共同成熟 RGB 初始化上的固定子集微调

**建议只推进路线 B：正式 N42 的固定 last/EMA 作为共同初始化，冻结 2048 图 train 子集（约 11.38%），N-ft/C0-ft/C1-ft 各做同一 3 轮微调，再各评价一次完整 dev。它最快回答“现有成熟 RGB 检测器能否从这项 KD 获得额外收益”，降低从弱初始模型短训导致的筛选混杂；不能替代从通用初始化训练到 E200 的方法判断。**

本文件为独立方案建议，未启动训练或评价，未修改现行长训、原始结果或公共索引。使用已有实测和本地小回执；遵循本项目不计算新 hash 的要求，以来源路径及原回执追溯。

## 现有证据与两条路线的区别

完整 E200 N seed0/42/123 的原生 mAP50–95 为 54.346185/54.513608/54.407436%；对应 C0 为 54.772186/54.658162/54.636847%。C0−N 三 seed 为 +0.266655±0.144373pp；其损伤专项复核仍为 REVIEW_REQUIRED，不能凭快筛解除。

相同通用初始化的完整 train、seed42 E8 得到 N/C0/C1 mAP 43.376542/43.920584/43.408107%；C1−N +0.031565pp、C1−C0 −0.512477pp。E8 N 比正式 E200 N42 低 11.137066pp，且 warmup 占 3/8=37.5%。这说明 E8 与成熟检测器处于不同性能阶段；**尚不能据此证明 E8 对 C1 的排序错误，也不能证明长训会翻转排序。**

|路线|实际回答的问题|速度与主要局限|
|---|---|---|
|A：通用初始化、固定 1799 图、独立 E8/E12|在低数据量、少更新的新训练任务中，KD 是否改善早期学习|B32 约 57 批/轮，每臂约 456/684 批；比已完成 E8 的 4504 批更少。减少图数不等于模型更快成熟，可能放大弱初始化、数据覆盖不足和稀有类不足造成的筛选误差。不能用于消除 E8 欠收敛疑虑。|
|B：共同成熟 N42、固定 2048 图、固定 3 轮微调|在相同额外数据与优化预算下，KD 是否优于纯监督继续微调；是否优于现有 C0|192 批/臂；从已有检测能力出发，直接测局部适应。但模型已见过完整 train，不能称“仅用 10% 数据训练”，也不能测试 KD 从头塑造表示的长期价值。B 的主方案采用 2048 图，不冒称恰好 10%。|

路线 A 可以用于以后专门研究低数据量学习，本轮不与 B 并行增加矩阵。若只是把 A 的 8/12 轮放大到几十轮以补更新，它已是另一预算与问题，不能看结果后临时延长。

## 唯一建议主路线及最小对照

固定 **N-ft、C0-ft、C1-ft 三臂**，seed42，每臂 3 个完整 subset epoch；2048 图/B32 恰为 64 批/轮、192 批/臂。N-ft 是去除 KD 的必要对照；C0-ft 是判断 C1 是否值得替换现有方法的必要对照。只比较 C1-ft 与未微调 N42，会混入额外监督训练；只比较 C1-ft 与 N-ft，无法回答它是否胜过已有 C0。

- 共同起点使用正式 `full_weight0_s42_attempt1/weights/last.pt` 的已接受固定 EMA 权重；不混用旧 native RGB、C0 权重或不同 seed。选择 42 为既定共同实验编号，不按三个 N 的 AP 排名选起点。原冻结 teacher 与 RGB reference **保持原来源**；student 初始化换成 N42 不意味着把 reference 也换成 N42。
- 仅从已治理的 17990 张 train 中，在读取新 AP 前按固定随机种子，以 source×密度×面积作自然分层，抽取并保存 2048 张 roster。分层边界、配额及抽样种子由执行协议事前固定，复用既有组/标签身份，记录五类与各层覆盖；不按教师可修复率、loss 或 dev AP 挑图，不为稀有类额外过采样后仍称自然比例。三臂相同 subset、loader 顺序和增强随机规则，mosaic 的辅助图也只能来自该 subset；dev/test 不进入抽样。2048/17990 约为 11.38%；这是按图像抽样，密度/面积用于分层，不是按对象数截取样本。
- N-ft 保持同 wrapper 的 weight0 路径，本轮不另开 native fastpath，以免优化入口改变 loader/增强随机流而混入方法差异。三臂均从相同权重 fresh-start，重新建立 optimizer、scaler 和 EMA；不是恢复原 E200 optimizer/EMA 更新计数的断点续训。B32/nbs64/workers4/imgsz640、AMP、SGD、原增强与权重衰减等共同保持。冻结 3 轮末 EMA，只在末端评价一次，不挑 best，不为单臂补成功更新。记录实际批数、成功更新、AMP skip 与 EMA 计数。
- 微调必须另立共同短日程，不能把原 `warmup_epochs=3` 生搬到 1–3 轮。根任务已选择固定 `lr0=0.001, lrf=0.1, cos_lr=False, warmup_epochs=0`，三臂相同，原 momentum 保持；这是预先选择的微调设置，**不是经验证最优值，也不是原 E200 的继续日程**。不扫描参数，不因某臂 AP 不佳重试 LR。`lrf` 是终点倍率参数；若沿用原 `lf(epoch)=max(1−epoch/epochs,0)×(1−lrf)+lrf` 的线性实现，3 轮实际使用的倍率为 1/0.7/0.4，不应把最后一个已执行 epoch 的 LR 写成 0.0001。实际 LR/accumulation 轨迹须按原 trainer 记录。
- λ 固定为 N=0、C0=0.1、C1=0.09227393550836771，沿用已接受 selected-only C1 实现与原选择规则。原 λ 校准发生在原训练状态，不能保证成熟模型上的梯度剂量仍相等；只记录实际有效 KD/选择计数及数值有限性，不自动重调 λ。无有效 KD 暴露时，只能报告本配方未形成干预，不能把阴性差值当成知识无用。
- 复用同一个已接受原生 evaluator，在完整 Drone dev 1469 图/22462 GT 上评价各末端一次。报告 mAP50–95、AP50、AP75 和原五类 AP，单位分别为百分制原值与 pp 差；不另建小 dev、不加 TIDE/新阈值诊断。已有相同口径 N42 未微调结果作为固定起点参照，不重复评价它。

主要对比是 `C1-ft − N-ft` 和 `C1-ft − C0-ft`；辅助报告各臂相对未微调 N42 的变化，识别是否三臂都因本次微调退化。C0/C1 的损失、表示与梯度剂量存在差别，快筛不具备非目标类信息、跨模态独有价值或某个损失组件的因果归因能力。

## 小时级预算的依据与边界

已完成 E8 的实际训练入口平均为 N/C0/C1：0.678905/0.430529/0.975035 秒/批；此前正常统计频率的 30 批实测为 0.858475/0.890618/2.475788 秒/批。它们来自不同共享负载，均不能承诺新的短微调速度。完整 dev 评价约 14.5–15.7 秒/臂。

以 2048 图、B32、64 批/轮估算，3 轮三臂共 576 个训练 batch。用上述两套实测作粗预算，训练约 **6.67–13.52 分钟**，三份评价合计约 45 秒；这只是按批量外推，短任务启动、数据准备、首轮缓存和峰值核验开销占比会更高。**预留一次资源窗口内 1–2 小时交付是合理预算目标，不能承诺从当前时刻开始的排队时间。** 入口必须核对实际 loader 每轮为 64 批，而不是只按配置图数宣称完成 192 批。

三臂通过原 globallease 串行，共用一个可准入槽；不假设有三张空卡，也不因快筛绕过显存/RSS实测及每卡并发限制。现有旧长训是否暂停由根任务按用户新指令单独处理，本建议不会隐式停止它们。只需复用适用的已接受执行/数值证据，并核对这次初始化、subset 和微调日程的实际入口；无需为了同一源码再建大型等价诊断矩阵。

## 预先确定的停止与扩展规则

1. **固定预算停止**：各臂严格 3 轮，只读一次固定末端；三臂结束即交付。技术失败、非有限数值、GT/初始化/日程不匹配、资源越界时保留 attempt，停止该比较并标无效，不把失败臂视为低 AP。共同额外样本预算不变，AMP 差异如实报告，不能单臂多训补齐。
2. **没有方法淘汰捷径**：若 C1-ft 未同时超过 N-ft 与 C0-ft，或三臂微调都不如固定起点，记录本次局部微调没有可用优势，停止沿本配方追加轮数/调参。结果不构成 C1 从头 E200 无效，也不能回过头宣称 E8 排序已被证明可靠。
3. **正方向也不直接长训**：若 C1-ft 同时高于两个匹配对照且不低于未微调起点，AP50/AP75 没有反向下降、干预有效且技术检查通过，只列为下一次有界独立重复的候选。正负号用于预登记分流，**不是显著性或正式收益门槛**；非常小的正差仍可能偶然。不自动启动 E200、不自动扩大 subset/seed/超参搜索，也不借用原 E200 的 0.10pp 阈值。下一步须先冻结一个独立重复，不能从多个重试中挑正例。
4. **不解除已有限制**：C0 的 REVIEW_REQUIRED 保持；不据此升级跨模态归因、非目标类机制、定位或论文增益。若最终主张是成熟 detector 的轻量微调，则正式验证也应围绕该新方法做独立多 seed 与必要内容对照；若主张仍是从头训练提升，仍须匹配完整训练证据。单 seed、单 subset、数十到百次更新不能替代任一正式主张。
