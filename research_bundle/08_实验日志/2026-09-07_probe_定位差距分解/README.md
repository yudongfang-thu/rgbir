# 定位差距分解探针（DroneVehicle val，2026-09-07）

> **2026-09-07 实施勘误（先读）**：下述原结论保留为历史记录。“夜间”实际为冻结亮度代理分桶；16.1% 仅是特定后处理阈值下的对象线索，不能直接视为可蒸馏比例。B 桶实现未同时要求教师优，不能称“双优”；D/E 桶不能证明没有低置信或粗候选。师生框 IoU 均值不能证明物理配准或同 anchor DFL 可迁移。以 [逐项勘误](../2026-09-07_audit_RGBIR实施起点/PROBE_ERRATA.md) 与 [新 D1/D2 诊断](../2026-09-07_probe_TaskConditional机会诊断/README.md) 为当前口径。

> **一句话**：oev2-loc（定位对称蒸馏）的目标市场被量化证实——夜间 **16.1% 的 GT 对象**是"学生检出但定位差（IoU∈[0.5,0.75)）、教师定位优（≥0.75）"的可恢复市场（day 仅 2.0%），且师生框 IoU 0.728 表明对应可行。
> 服务器产物：`94:RGBT_campaign/artifacts/loc_gap_probe_20260907/{summary.json,per_image.csv}`。

## 目的
把夜间 +22.2 AP75 的定位差距分解为"可蒸（学生有观测）"与"不可蒸（学生无观测）"，回答 oev2-loc 立项依据。

## 设置
- 教师 = IR native s42（b32a2）；学生 = RGB native s42（cgkd_w1，协议匹配）；conf=0.10，检测阈值 IoU≥0.5，定位优阈值 IoU≥0.75，类感知贪心匹配；亮度阈值 78.283（沿 p3 冻结值）
- 五桶定义：A=学生检出且学生<0.75但教师≥0.75（**目标市场**）；B=双优；C=学生检出但教师也不优；D=学生漏检教师检出（无观测）；E=双漏

## 结果

| 桶（占 GT %） | day (n=10,781) | night (n=11,681) |
|---|---|---|
| **A 可恢复定位** | 220（**2.0%**） | **1,876（16.1%）** |
| B 已优 | 89.4% | 60.9% |
| C 教师不优 | 4.0% | 8.6% |
| D 无观测 | 1.5% | 10.7% |
| E 双漏 | 3.1% | 3.7% |

**A 类细节**：car 主导（1,930/2,096）；学生 IoU 均值 0.680 vs 教师 0.851（**+0.171 的可学习余量**）；**师生框 IoU 0.728**（teacher box 可直接作对应目标）。

## 结论
1. **oev2-loc 有真实市场**：夜间 16.1% 的对象（~1,876 个/val 集）定位可通过教师恢复，day 仅 2.0%——与昼夜 AP75 差距（+22.2）的分布一致；D 类（10.7%）不可蒸，印证审计"无观测目标最难学"的警告。
2. **对应机制可行**：师生框 IoU 0.728 意味着"教师框+学生框"联合匹配即可建立逐对象对应（oev1 的资格逻辑可复用）。
3. **定位版比判别版市场更大**：oev1 蒸判别拿 +0.9 的市场（资格对象中教师判别更优的比例）远小于 16.1% 的定位市场——oev2-loc 的理论上限更高。
4. 类别高度集中于 car：若做类别分析，需注意 freight car/truck 的 A 类极少（各 50/66）。

## 局限
- 单 seed（s42）师生对；conf=0.10 阈值下 D/E 的划分敏感于阈值选择
- 探针测的是"教师框更准"的存在性，不是"学生能学会"——AP75 从 0.68 提到 0.85 对 mAP 的边际贡献需训练验证
- A 类对 mAP50-95 的贡献未直接计算（需按 IoU 段位积分），下步可补
