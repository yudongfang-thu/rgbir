# E8 三臂阶段判断：已取得快速反馈，C1 未显示早期优势

**N/C0/C1 的 seed42 固定 E8 训练及完整 dev 独立评估全部完成，队列共用约 2 小时 40 分钟。C1−N 为 +0.031565pp，C1−C0 为 −0.512477pp；这次短程结果不支持 C1 已优于 C0，不能据此判定 E200 最终效果或停止在跑三 seed。**

## 1. 做了什么，比较是否成立

这是在读取新 AP 前冻结的独立短程筛查：Drone train17990/dev1469，dev 共 22462 个 GT；原 YOLO11n 通用初始化、seed42、640、batch32/nbs64/workers4、SGD/AMP、原增强与正式数据随机性。三臂共同 8 轮及 8 轮 LR 日程，warmup 保留 3 轮；固定 last/EMA，完整 dev 原生 AP，不选 best、不访问封存 test。

|实验|额外学习内容|实际 λ|
|---|---|---:|
|N|同 wrapper 的 weight0|0|
|C0|原 OEv1 对象判别证据，原区域/尺度压缩与 SmoothL1|0.1|
|C1|相同选择基础，P3/P4 各类别前景相对背景 raw logits，逐类 Bernoulli KL|0.09227393550836771|

C1 使用已经通过旧新各 24 次真实更新一致性验证的 selected-only 实现，保留原池化算术与 FP32 cast。C1 的 λ 沿用先前梯度校准，没有因 E8 AP 重调；C0 和 C1 的表示、损失及实际梯度剂量并非完全相同，不能把两者差异单独归因于非目标类信息。

三臂均为 4504 批、2667 次成功更新、7 次 AMP skip、2674 次 attempt/EMA。实际训练 args 除运行名/保存目录外一致，实际评估合同全字典一致，源与配置预定差异独立核对通过。完整共同 dev roster 字节相同。端点复核为 N 17 项、C0 18 项、C1 26 项；见三个端点报告。

C1 相对 C0 在 van、freight car 上更高，但 truck、bus 的下降抵消了这些提高。因此，本次结果没有显示少数类别获得一致改善，也没有显示增加分类传递内容自动带来更高宏平均 AP。

这与此前数据分析并不矛盾：对象/错误 oracle 说明可能存在可修复机会，不保证具体 KL 算子、对象表示及优化过程能够兑现。此次筛查也没有运行 C1_y，不能证明非目标类项无效或有害；更不能推出局部特征图蒸馏会更好。

完整逐类 AP50/AP75 和 P/R 原值见 [自动生成表格](COMPARISON_TABLES.md)。原生 evaluator 的 P/R 数值不是本次新增的固定阈值对象损伤统计，不能拿 P/R 变化替代背景误检、修复或负迁移的因果判断。
