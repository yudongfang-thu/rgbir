# L3 loss implementation contract

`l3_distribution_loss.compute(student, teacher, reference, batch, strides=(8,16,32), variant='L3-DFL'|'L3-GT') -> (unweighted_scalar, JSON_stats)`. Raw boxes are B x 64 x A logits, not decoded boxes. Caller alone composes `native.sum() + B_actual * lambda * scalar`. No coefficient or B multiplier is applied inside. Temperature is fixed at 2; four-edge mean KL is multiplied by 4 and divided by `max(1, coarse_R_base_count)`.

Original L2 matching, label-pair IoU, R base/native unique ownership/support/confidence selection and R reliability/gap remain. Its independent teacher-anchor search is replaced by this protocol's teacher check at the selected R anchor. Teacher ownGT quality uses original detached T=1 FP32 expectation; mapped RGB quality uses original annotation-coordinate mapping. Complete positive mass must pass accepted rational transport support. T=2 softmax is computed before transport, using the saved-math operator definition on actual detached logits, not square root of an already transported T=1 target.

The accepted `probability_transport.py` is copied byte-for-byte from transport/. Runtime helpers `selection_adapter` and `localization_loss` are loaded from the existing pinned runtime; localization_loss source path is enforced. The unchanged `localization_box_v2.py` is needed only by the CPU comparison test, not by L3 compute.

All four transported target sides must remain finite and preserve every positive mass when converted from FP64 to FP32. Positive q64 becoming q32=0 rejects the entire object and increments `target_float32_rejected`; legitimate exact zero is retained without epsilon. Rejection does not shrink the base denominator. This extends the explicit target-representation contract, not the executed CPU transport result. Finite rounding of nonzero mass is recorded by the target dtype; no renormalization is performed after transport. GT uses unclamped RGB adjacent-bin probabilities followed by the separately frozen sqrt/sum temperature-2 rule.

DFL and GT repeat the exact same selection, target support and target precision conditions. Stats preserve `base_count`, `normalizer`, `selected_count`, `selected_anchors`, `selected_object_ids`, plus `selection_identity`, full-support/precision rejections and per-base actual gate values. Unexecuted teacher gates remain null. Teacher/reference/targets detach; student scores do not control selection or receive KD gradient. Only selected student DFL logits receive KD gradient. Empty selection returns a connected differentiable zero without summing unused logits.
