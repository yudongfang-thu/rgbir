# L2目标审计：高余弦来自什么，差异还剩什么

**30个selected对象出现的120条边中，47条因同向饱和给出完全相同的教师/GT输出导数，63条同向但幅度不同，10条反向（涉及8个对象）。教师目标明显靠近GT，却既非逐边相同，也未证明比GT更有学习价值。** 本审计只使用旧八批记录；不改变门/目标/λ、不进行forward、GPU、训练或文件hash。

[PLAN](PLAN.md) 先冻结公式与读出，随后 [5项合成真值](test_targets_cpu.py) 通过 [CPU_attempt1.json](CPU_attempt1.json)，再执行真实分析。原值及30条带原框/anchor的对象记录在 [output_attempt1](output_attempt1/)，源码为 [audit_targets.py](audit_targets.py)。root完成了 [94实际source身份核对](../SOURCE_IDENTITY.json)；本次使用的早期捕获 `localization_box_v2.py` 也与该已核本地源逐字节相同。没有改旧记录或旧短训结论。

## 实际学习位置、目标和分母

R先在P3/P4、GT配对/支持域/唯一owner等约束后，按**confidence→IoU→anchor ID**选参考anchor。满足R可靠且IoU<.70后，T在自己的GT候选中按**自身GT IoU→confidence→anchor ID**选教师anchor，再检查映射RGB质量及领先>.05。学生学习位置是R选定anchor；教师anchor可以不同，本次30个selected仅1个R/T anchor相同。

教师目标只经过 `DFL概率期望→xyxy框→GT对象坐标`。该L2没有把完整DFL分布形状、熵或局部特征传给学生。坐标映射用双GT定义的轴仿射，不是估计的物理配准。令

`z(b;g)=(b−[gx1,gy1,gx1,gy1])/[gw,gh,gw,gh]`，教师目标 `t=z(mapped_teacher_box;g)`，GT控制 `q=(0,0,1,1)`。

原单位损失为 `Σselected mean_4edges SmoothL1(z(student_box;g)−target, β=.1) / M`，`M=max(1,base_count)`，不是selected数量。`direction_criterion` 在原native损失外加 `B×λ×KD`，本校准B=32、最终两L2系数均1；L2-box与GT共用原选择、R anchor和分母。本审计分别保留单位、`1/(4M)`和像素链式缩放后的导数，不混成一个无单位“梯度”。

## 记录覆盖与可复算边界

八批共256次图像出现、256张不同图，649个base对象出现；selected为30个、26张图，没有跨批重复图，4张图各有2个selected。全八批未保留像首批那样的稳定原生GT追踪，故本报告用批次/增强后GT行作为发生ID，不伪造原annotation行号。

649条base的RGB/IR GT框全部逐字段相同，映射数学上为恒等。32条非null教师目标中，30条selected；但浮点重构不总逐位相同：batch4/rgb12最大差1.52587890625e−5像素，batch7/rgb21为7.62939453125e−6像素（均selected），其余非null映射框exact。**分析使用原mapped_teacher_box，没有替换成IR原框**；selected中28/30映射框逐位相同。共享标注不证明物理对应。

记录没有任何 `student_box` 字段。因此用保存的R框定义 `r=z(reference_box;g)`，复算的是**R输出处代理**；校准恢复共同初始化、BN冻结及标量接近，都不能补造学生raw/坐标逐元素exact。没有DFL概率与计算图，也不能重建logit梯度、全参数Jacobian或实际参数更新。

## 高cosine由哪些边构成

在R参考点，令 `dT=clip((r−t)/.1,−1,1)`，`dGT=clip((r−q)/.1,−1,1)`。这是损失对归一化输出坐标的导数；实际坐标下降方向取负号。SmoothL1在 `|error|<.1` 是二次损失/线性导数区，区外是线性损失/饱和导数区。

|两种误差所处区域|边数/120|含义|
|---|---:|---|
|均同向饱和|47|目标虽然不同，导数均为同一个+1或−1，完全相同|
|两者均在二次区|58|导数保留目标残差差别，`dT−dGT=−(t−q)/.1`|
|仅一方饱和|15|一边截为±1，另一边仍改变幅度|
|均饱和但反向|0|本次没有|

GT导数饱和61/120，teacher导数饱和48/120。按符号独立分解：47条同号且导数exact、63条同号不同量、10条反号，零导数0条。反号10条全部在两者二次区，涉及8个对象。

例如第1批RGB行25的y1：R相对GT偏差+0.026739，教师偏差+0.042461；GT导数+0.267386，教师导数−0.157225。GT会让该边减小，教师会让该边增大，即在这个参考输出点将这条已较准的边向GT外推。反过来，教师框整体可能仍更准，因为其余边改善更大；不能把这10条边直接称为训练负迁移或认为8个对象整个框方向错误。

未缩放的stack输出导数cosine为0.958663；按每批真实`1/(4M)`缩放后0.959681；再链式换成像素坐标并乘Bλ后0.980442。每对象cosine中位0.979339、最低0.819382。**同一记录仅改变坐标/分母权重，cosine也会变**，所以这些值不能当作共享参数梯度cosine。高总体相似性与“教师目标相对R误差很小、47边饱和抹去目标差”相容；58个二次区边仍保留细微目标差，不能只凭高cos将两目标视为等价。

## 哪些问题不能靠这份缓存回答

617/649条base没有mapped teacher目标；大多在前置门停止，未计算后门候选。本数据不能判断放宽门后这些对象将得到什么实际teacher目标、有效分布或新梯度。32个有目标中2个没有selected，可按旧门解释，但不能据30个成功选择外推全base。

缺学生selected框/原DFL logits及概率，不能在全部30对象上证明R就是当时学生输出，也不能由框期望反推4×reg_max分布；缺计算图/参数Jacobian，不能比较目标差造成的实际参数方向与强度；缺后续轨迹，不知道反向边是否实际造成误差。旧三轮L2未胜GT的结果保持，不因这份解释被改写。

这版L2传入的是经过GT筛选的框期望，额外于GT的内容主要是这些近GT残差及其对修正幅度/少量边方向的改变，**尚未证实是有效的额外知识，更不是特征带宽收益**。仅扩大门不会自动改变这条目标路径。当前证据可支持root决定是否停止“只扩门”的路线；任何替代内容都需另立清楚协议，本审计不自动增训或无限追加探针。
