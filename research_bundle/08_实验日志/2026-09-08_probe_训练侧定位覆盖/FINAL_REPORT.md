# LLVIP 训练侧定位机会：原 C 与历史 L2 的真实覆盖

**训练侧确实存在“RGB已检出但框不够准”的对象；旧 L2 的绝对 IoU0.70 前置门会排除一部分这类机会。固定首32训练图的80个GT中，有11个双方通过IoU0.5、仅IR通过IoU0.75；历史同批 L2 选中4个，另外7个均止于参考框IoU<0.70条件。这个发现支持检查门控覆盖，但不证明放宽门就会改善训练。**

本轮复用现有post-NMS缓存与旧校准记录，**0 GPU、0新前向、0训练更新**。没有按原备用范围追加第2–4批，因为已有缓存足以回答当前这一具体覆盖问题。单批总体比例仍不确定，备用范围保留为后续需要时的上限。

## 原生匹配下的定位对象

保留原score>0.25、NMS后的预测，分别独立调用固定原生源码进行IoU0.5与0.75的一对一匹配。S/R使用成熟RGB初始模型，T为旧IR42；原始图、增强、GT及模型身份见[前次同帧合同](../2026-09-08_probe_同帧选择覆盖/FINAL_REPORT.md)。

|模型|IoU0.5正确|IoU0.75正确|
|---|---:|---:|
|S / R|77 / 80|61 / 80|
|T|78 / 80|72 / 80|

双方在IoU0.5均正确的77个对象，进一步分为：双方均过0.75的60个、仅T过0.75的11个、仅S过0.75的1个、双方均不过0.75的5个。原IoU0.5下仅T正确的1个和双方未匹配的2个另列，不混入粗检出定位集合。

11个定位机会覆盖8张图，原C的base/eligible/selected分别为11/10/8，selected涉及6张图。这个结果是原C覆盖，不是L覆盖或梯度份额。反向的1个定位对象进入C base，但不进入eligible/selected，不能单凭此宣称负迁移已消除。

## 与历史 L2 的记录关联

旧八批校准的第一批与本次32图顺序完全相同，79条L2 base record的图索引、RGB/IR全局GT行、类别及双GT框逐项一致。校准与见证的S权重路径/大小/时间戳一致，配置只有校准结果路径的阶段性差别。通过这些已核对身份连接到80个稳定GT ID，读取历史实际门和selected，没有重跑或重算L2选择。

|11个定位机会的历史L2环节|保留对象数|
|---|---:|
|base|11|
|参考类别/置信度可靠|11|
|参考框 IoU < 0.70|4|
|教师自身质量|4|
|映射目标质量及相对领先、最终selected|4|

另外7个对象的历史reference_iou均≥0.70，全部在参考定位缺口门退出；教师后门尚未执行，其相关值为null。不能把它们排除的原因写成教师不够好。4个被L2选中的定位机会也全部被原C选中。

全80对象的历史L2 selected为7个，其中与C同选6个、仅L2选1个；其余为仅C26个、两边均未选47个。11个定位机会之外仍有其他L2选择，不能把4当整批L2的总K。

另有一个独立native-box代理：11个对象中，S原生匹配框IoU<0.70的4个、T在自身GT上的IoU领先>0.05的10个、两条件同时满足的4个。这次数字碰巧与实际L2机会覆盖一致，但二者语义不同；实际L2还受P3/P4、支撑范围、唯一归属、confidence-first参考anchor和教师目标选择约束，不能以后都用native代理替代。

## 对下一步的影响

1. **“训练中完全没有定位机会”不成立于这一批。** 数据中存在可连接到学生粗框的教师定位差异，不能把旧L1几何阻塞等同于所有定位信息无效。
2. **绝对参考IoU上限确实限制覆盖。** 原L2的0.70门与本轮0.75诊断之间存在一批对象，但增加覆盖、增加实际KD剂量与教师内容有效是不同解释。旧门和已完成训练结果保持原身份，本轮不现场改0.70或开启新长训。
3. **旧L2小幅负结果还不能只归因于门过严。** 原短训中教师/GT目标导数接近、实际梯度剂量偏小的证据仍在；即便覆盖增加，也要看教师内容是否超过同掩码GT控制。后续若提出门的新版本，须先明确新对象集、固定剂量/控制和短程判断条件。

本轮没有用dev的1,304个定位机会挑训练图，没有把单批train和完整dev比例差称为过拟合，也没有解除L1物理几何合同。局部特征或logit哪种内容更可学，不能从此表直接决定。
