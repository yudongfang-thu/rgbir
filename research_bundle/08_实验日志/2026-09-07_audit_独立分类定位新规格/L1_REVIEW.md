# L1 / L_GT 专项审阅与下一步建议

> **结论：新规格的单分支策略、DFL/GT 数学定义及固定参考选样可以采用；现有代码尚未满足其新的训练模式校准和覆盖门。最先要解决的是“有限 exact-image 几何审核能否给自然训练流提供足够覆盖”，然后才能安排 L1 长训。R IoU<0.70 的窄机会定义仍未解决，只是被新规格明确继承。**

本审阅读取独立分类定位 v2.0 MD、ZIP 的参考内核与 18 项测试源码，以及现行 localization_loss.py、task_criterion.py、geometry_contract.py、calibrate_gradient_scale.py、既有 D1/D2 和最近门控敏感性审计。新增一次只读 CPU roster 交叉计数。没有加载模型、调用 GPU、修改阈值、改变在跑任务或把未知几何设成通过。

## 1. 可以直接保留的定义

1. **L1 本来就是 logits/分布蒸馏。** 每对象一个 P3/P4 anchor，四边 × 实际 reg_max=16；质量门按温度 1 解码，迁移按温度 2 计算 KL(T‖S)×τ²/4。不要再将“定位升级到 logits”当作新增工作。
2. **冻结 R 预选，而非当前 S 动态选择。** 对象对应先于候选，R confidence→R IoU→全局 anchor ID 的破平局稳定；教师必须在实际同一个 anchor 通过质量门，不能从教师别处借好框。
3. **分母是 pre-teacher E_L。** 几何、标签、未 clamp 支撑、全部 RGB GT 的 native 几何唯一归属、R 粗候选完成后形成 E；再做教师/参考质量门。损失除 E 而非 selected。有效对象少时不会按 selected 数额外放大。
4. **L_GT 保持同 E、同 anchor、同 mask、同 λ，仅换内容。** 两 bin q 变为 q^(1/τ) 后归一化，匹配 softmax(S/τ)，其温度 1 的最优概率仍对应原 q（含零支持时按极限理解）。它是同掩码温度化 GT 重监督，仍使用 IR 选择信息，不能叫 RGB-only。
5. **不从形状相等推出物理相等。** raw-box `[B,4R,A]→[B,A,4,R]` 只是布局契约；一般映射 W 下只采样教师 logits 并不足以转换参考点、方向、距离尺度的 bin 语义。首版不引入该映射是合理的边界。
6. **不新增隐藏的当前学生 fg_mask 门。** 记录 same_object / native_background / different_object；静态唯一几何归属不等于当前 native TAL 最终正样本。

现行 localization_loss.py 与新包 DFL 内核在 KL 方向、四边平均、温度、GT 温度化、分母和教师 detach 上一致。包中的 18 个合成测试不能证明真实 raw layout、selection、augmentation 或 trainer 等价已经通过。

## 2. 实施前必须解决的接口/代码差异

### 2.1 旧校准器不满足新校准合同

现行 `calibrate_gradient_scale.py` 的实际行为是：载入 R 权重后 `model.eval()`；不按 batch 重新恢复参数和 BN buffers；只要有一个非零批次就可能出 `CALIBRATED`；只记录模块索引，没有实际 parameter names，也没有完整来源分布和 16/64 资格判断。

新规格第 8 节则要求学生副本处于训练模式、每批前恢复同一 R 状态、至少 16 个有限非零训练 batch、实际参数名字和明确的固定样本流。**因此不能直接复用旧校准 receipt 格式或以旧校准器的存在声称 READY。**

需新增版本校准器：

- 每批恢复学生参数和 buffers 后 train()，T/R 保持 eval/no_grad；不 step，不推进正式训练 RNG。
- 明确 native_total 已带原生 batch convention，unit_L 从 `last_components` 读取时已含 B，禁止再乘一次 B。
- 对所有范数/比值做有限性检查；不把 native=0、L>0 算作有效配平；保存零梯度、非有限原因和 64 批逐批记录。
- 执行 ≥16/64、非单图/单来源覆盖门，并在配置中明确“非集中”具体判据。新规格目前未给出后者的数值定义，不能实现者临时解释。
- 固定真实 Θ parameter names；L_GT 复用 λ但另测其梯度量。formal-ready 验证 receipt 与实际任务、数据、T/R、geometry、selection 配置和单分支代码一致。
- 24 次成功更新 canary 检查 L1 对 raw DFL 有直接梯度、对 raw scores 无直接 KD 梯度；检查与原生共享参数的梯度方向，不能用现有冻结 R logit 余弦替代。

### 2.2 旧 trainer 是 C+L 模块，新的单任务身份需要显式实现

旧 `task_criterion.py` 即使 C-only/N 也计算完整 C/L；L-only 将 C 权重置 0，仍计算 C。新接口需单一 task 分派并拒绝联合参数。保留 C0/N 等价验收，不能因删掉无效分支而默认训练轨迹不变。N/C0 等价失败时先修代码/随机状态，不能把新 N 与旧 C0 拼接。

### 2.3 “局部补点”和当前 geometry contract 不是同一接口

当前 contract 要求六个点覆盖**整幅原图的至少三个象限**。新第 7.1 节建议把审核重点放到潜在对象邻域；若仅在一个对象周围标六点，该区域常在图像一个象限，会被旧代码拒绝。

需要在实现前明确二选一，而不是边审核边隐式换规则：

- 保留现有全图象限要求，并额外补对象附近/边界附近的独立结构点；或
- 单独登记 `local_support_geometry_v2`，定义局部检查区域、局部点分布、位置不确定度、独立复核和未测区域拒绝；不得外推整个 folder/prefix，不得通过拟合 GT 框构造证据。

当前 mask 检查 RGB GT 四角同时在两套点凸包中，但没有显式检查匹配 IR GT 的边界邻域。新文字“覆盖该目标及相应边界附近”应落实成精确的支持域定义和测试；至少明确两侧目标边界、anchor 所处区域及接受的近似误差范围。背景点凸包内部物理对应一致仍是经验假设，凸包算法本身并没有验证每个内部点，尤其不能消除目标与背景不同深度、遮挡和动态物体误差。

## 3. 新增 CPU 证据：有限审核与自然训练流信号门可能不协调

新增脚本 `l1_geometry_coverage_audit.py` 按已知数据集与 stem 对齐原图/processed 路径，仅作诊断统计，不能生成正式几何授权。

| 数据集 | 原 roster 条目 | 唯一图像 | 已有 D2 基础 E 记录覆盖其中 | 其中含原 L selected 对象 |
|---|---:|---:|---:|---:|
| Drone | 258 | **238** | 160 | **20** |
| LLVIP | 42 | 42 | 31 | **4** |

重复来自同一来源首/中/末抽样，不应把 258 条自动写成 258 个独立图像。未出现在 D2 基础表的 roster 图不能当作“无机会”，因为基础表不是全部图像/全部被拒对象清单。上表也不表示其中任何一图已几何通过。

更关键的是 exact-image 授权规模。按 LLVIP train=9619、batch32、64 批、均匀独立抽样的简化估算，即使原 roster 的全部 42 图每次都能提供 L，出现这些图的非空 batch 数期望也只有：

`64 × [1−(1−42/9619)^32] = 8.36 批`。

这**不是实际固定 DataLoader 的预测，也不是硬上界**，但提示 ≥16/64 与“只补原42图且不外推”不协调。Drone 238 图全有效对应约22.21批；若仅采用当前已知含静态 selected 的20图，则约2.24批。真实增强和质量过滤还会改变这些数值。

因此下一步不应直接承诺“一天标若干图→定位长训”。应先用 CPU 重放自然 64 批真实源图/增强元数据，计算拟审核 exact-image 集合最多能命中多少 batch。**若这个确切命中上界低于16，继续只审核该名单不可能满足固定合同。** 这是算力和人工投入的可行性检查，不是放松质量门。

应把两个目的分开登记：原300条 roster 是数据集几何抽样诊断；能产生自然训练信号的 exact-image 授权清单是训练覆盖工程。不能因抽样诊断通过就把整个来源文件夹当作相机标定组。

## 4. R IoU<0.70：不是内核 bug，但下一步不能忽略

新第 5.5 节完整继承旧 `.70` 上限。最近已有训练诊断明确显示：在同 E、同 anchor、同其它质量门下，Drone selected/GT 从626/31931=1.96%变为 `.80` 时2115/31931=6.62%；LLVIP由211/5592=3.77%变为598/5592=10.69%。教师领先 `>0.05` 保持不变。

这表明原条件研究的是**冻结强参考的实际选中 anchor 仍然绝对不足时**能否蒸馏，而非一般的“教师有定位增量”。已训练完的 R 好，不代表通用初始化的 S 已经好。现有 D2 也有同对象另一个 anchor 已定位良好者，不能改称“学生检出了但定位不准”。

建议下一步计划明确以下身份：

- 若严格采用新规格：保留 L1-strict07，并承认其覆盖窄，先检验几何/真实64批是否达到资格；不把“继承旧协议”解释成 `.70` 更正确。
- 若决定利用刚才诊断重新定义机会：另立 L1-rel08 或 advantage-only，先冻结选择、探索来源和比较关系，再校准/长训；不继续沿用旧 L1 的 ID。**本审阅没有选择或修改新阈值。**

不建议同时扫多组阈值。相对优势、正确对象对应、未 clamp DFL 支撑不是应与 `.70` 一起随意放开的条件。单纯改质量门也无法解决尚未核验的几何区域。

## 5. 有限且可执行的几何补证流程

1. **0–2小时：先算覆盖上界。** CPU 生成固定自然64批的图像/增强索引；现有 train D2 候选按来源、尺度和曝光代理分层，明确 exact-image 候选清单与静态机会身份。先检查该名单理论命中 batch 数，不能为了16/64专门过采样候选而继续声称原 recipe。
2. **2–6小时：小规模方法可行性审核。** 从已有 train D2 的候选图挑一个冻结、分来源的小名单（例如最多24对；20%独立复核），作为人工可辨认性/成本试样而非整套训练授权量承诺。标点时隐藏模型输出和 GT 边，采用能在 RGB/IR 中辨认的同一物理结构；预先记录为什么这些结构可辨认、位置不确定度和其与目标的空间/深度范围。难以辨认即 UNKNOWN，禁止勉强给高精度坐标。
3. **一次性决定是否扩大。** 若审核成功率、区域覆盖和自然流命中共同表明可达到16/64，列出具体需要审核的唯一图数量与人力预算，扩大 train-only exact-image 清单；否则结束这一天的 L 几何冲刺，写 `BLOCKED_COVERAGE_BUDGET`。不要以无限标点消耗替代方法进度。
4. **已核验 mask 上重做 D2 与梯度。** 原图局部支持域经实际 RGB/IR增强矩阵传播，按实际 stride/短边误差容差拒绝；丢弃裁剪移出区域、证据不足或不支持的变换。只对非零合格真实训练流做固定校准与 canary。
5. **只在全部通过后排 L1。** 不以 C 成功替代 L 资格，不新启 CL/CGT，不从 GPU 数或旧未核验626/211推断已 READY。L_GT 配置/核验同时就绪，但长训按冻结独立矩阵投入。

上述小时是 CPU/审核工作的预算窗口，不是定位长训启动承诺。若需要改变支持域模型，应在审核前登记新几何版本，而不是看 AP 后改变接受条件。

## 6. 必須记录而不必继续增加门的风险

- 教师框 IoU 较好不保证其 DFL 分布更优；记录 T/R/S 对 GT 两 bin CE、entropy、边界偏差和共享参数梯度冲突，但首版不顺手加入 entropy 或 CE 新门。
- L1/L_GT 同 λ并不等梯度剂量；内容结论需报告实际剂量，必要时另立剂量对照，不能谎称所有差异只来自信息内容。
- selected/E 的静态聚合不是实际 batch 平均剂量；记录空批、唯一图/对象/来源、每epoch累计剂量以及增强后的有效率。
- “三seed全正”是预登记的投入判据，不是统计显著性；无训练时只记 BLOCKED，不能记作 L 无效。
- 目前严门 selected 在 Drone 几乎集中 car/暗图/小目标，单分支净收益不能自动推广全部类别或昼夜；亮度是代理，来源 folder 是抽样层。
