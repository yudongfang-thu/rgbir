# 新规格的实验矩阵、基线与推进判据独立审阅

**结论：接受“C 与 L 分别证明效用、暂不融合”的策略替换，优先复用当前同代码 N/C0；但必须补齐最终保留分支的四臂归因预算，冻结随机性政策，并把 0.10 pp 明确标为新候选的开发投入门槛。新版最多 12 个训练只覆盖核心效用与两项内容消融，不等于投稿所需实验总量。**

本报告只读审阅用户提供的 MD、ZIP 和最新本地审计。未启动 GPU 作业、未重算 AP、未改动在跑实验和总计划。结果状态引用 **2026-09-07 11:19 +08:00**，不冒充审阅时刻的服务器快照。

## 1. 材料一致性与当前证据

- 外部 MD 与 ZIP 内同名 MD **逐字节一致**，均为 68,094 bytes。
- ZIP 有 8 个文件；README、参考内核、18 项 CPU 测试与 JSON/XML/log 回执齐备。包明确不含完整 trainer、真实几何验收或服务器训练成果。
- 规格引用 GitHub `7bfaf2f` 的 03:22 快照偏旧，但 §0.1 已允许现场绑定较晚原始结果。因此不用因包内旧快照重跑 N/C0。

现场六个固定 E200 last/EMA 端点已完整，Drone dev 1469 图：

| seed | N mAP (%) | C0 mAP (%) | C0−N (pp) |
|---|---:|---:|---:|
| 0 | 54.346185 | 54.772186 | +0.426001 |
| 42 | 54.513608 | 54.658162 | +0.144554 |
| 123 | 54.407436 | 54.636847 | +0.229411 |
| mean±样本 SD | 54.422410±0.084710 | 54.689065±0.072770 | +0.266655±0.144373 |

当前结论应为“冻结协议与其实际随机性下三 seed 同方向的小幅净增益”，不是显著性证明，也没有完成跨模态归因。AP75 为 2/3 正，报告 Recall 为 3/3 负；Recall 需统一操作点后才能解释具体损伤。

## 2. 新旧计划应如何替换

| 事项 | 审阅意见 |
|---|---|
| 旧 CL42、CGT42 首轮 | 尚未启动；登记 `DEFERRED_BY_INDEPENDENT_CL_V2`，不删除旧计划、失败探针或代码 |
| 新 C1 和 L1 | 分支独立，不以另一支成功作为技术准入；C1 不等 L 几何 |
| 已在跑 C0-random / shuffled / same-modal | 继续原任务、原配置与独立评估责任，不自动移交成 C1 或 L1 对照 |
| 旧 CL42−C42 ≥0.30 pp | 原方案的单 seed 算力扩展门，不再用于新版 C1/L1 判读 |
| 新三 seed ≥0.10 pp | 在看到 C1/L1 AP 前冻结，仅用于新候选的实际价值/投入判断；不追溯修改 C0 或旧 pilot 结果 |
| 融合 | 本轮不实现、不排队；单支结果完备后再提出下一阶段协议 |

从 seed42 技术首发到 seeds 0/123 的顺序可以固定为 **42→0→123**，三组完成后统一作主要决定。E200 seed42 不是可按 AP 停止其余 seed 的筛选器；仅技术故障、准入失败、资源越界等预先规定原因暂停。已经完成的 seed 不因方向不好改 seed 或替换 attempt。

新 0.10 门槛数值比旧 0.30 小，不应表述成“放宽同一成功标准”：比较的是不同方法与不同 estimand，且新方案要求完整三 seed。它仍然是研究者选择的成本阈值，不能称为 JSTARS 要求或统计显著性。

## 3. 当前 N/C0 能复用，但不要改数据流后继续复用

此前 native 审计已经发现旧 CGKD native 与当前 N 的 workers、trainer、训练期验证流程不同。当前 N 相对旧 native 均值 +0.468864 pp，只有 2/3 seed 上升；C0 相对旧 native 的 +0.735520 pp 不能当 KD 效果。

新方案应继承当前 OEv1 的 workers4、关闭训练验证、固定增强、通用初始化、batch/accumulation、optimizer/AMP/EMA 与独立端点。新的无 KD wrapper 与当前 N 应做真实多 batch、更新与 EMA 状态比较；不只验证 KD 项乘零。

建议的复用闭环：

1. 绑定 N/C0 六个 run 的实际 args、模型与评估回执；把旧 native 单独标为 `HISTORICAL_RECIPE_REFERENCE`。
2. 保持当前 loader generator 和全部增强语义不变。现有 generator 不含实验 seed，这一局限必须明示。
3. N/C0 兼容路径重放至少前 30 个真实 batch 的图像、双标签、样本顺序；覆盖 optimizer attempts、成功 update、AMP skips、EMA，完成 24 次成功更新的技术验收。
4. 用三个 seed 的初始权重实际比较，明确变化发生在哪些张量；允许称为“固定数据流下的初始化重复”，不能称为三套独立增强重复。
5. 通过兼容验收即可复用当前 N/C0，无需重训历史工程差值的完整因果分解后才开始 C1。

**不要在本轮顺便把 loader 改为每 seed 独立数据种子。**若后来确实要作该改动，应命名新 recipe/run family，重新跑该协议自己的 N 与被比较 C0；不能只更新 C1/L1 的数据流却借用旧 N/C0。旧结果仍然有效，只是不再匹配新 estimand。为完整随机性做新 campaign 是额外稳健性工作，不是当前基线“自动作废”。

标准 native 适配同 recipe 与 N 的轨迹比较可作为较小工程审计。若它不等价，先定位差异；不能用短测直接解释旧新 +0.469 pp 的 AP 来源，也不必无条件重跑全套老实验。

## 4. C1_y 和 L_GT 的顺序与判据应更具体

新规格已经正确指出 C1 比 C0 同时改变类别维度、尺度聚合和损失。C1_y 在相同结构、选择和 λ 下令 η=0，是必要的第一层消融；它只隔离新增非目标类项，仍有总梯度剂量变化。L_GT 同样不是完全 RGB-only，也不能证明同数值 λ 意味着同实际剂量。

合理的分批顺序是：

- 类别：C1×3 完成，对 N/C0 判断；有保留价值时再 C1_y×3，同时准备最终类别方法的同模态和 shuffled 对照。
- 定位：几何/信号准入后 L1×3，对 N 判断；有保留价值时再 L_GT×3。若资源能容纳 L_GT42 而其它 L1 seed 因合理依赖暂不可启动，可提前得到内容诊断，但不能据该单 seed 换门或 λ。
- C1/L1 无法达到主要效用门，不继续用融合“救结果”，也不因此声称所有 logit/定位蒸馏无效。

建议计划将模糊的“稳定优于内容对照”物化为事先规则，而非事后自由解释。可采用：

| 主要决策 | 建议冻结的最低条件 |
|---|---|
| C1 替代 C0 | C1−C0 三 seed 全正、mean≥0.10 pp，且 C1−N 满足同样效用条件；错误分析无未解释系统损伤 |
| L1 独立保留 | L1−N 三 seed 全正、mean≥0.10 pp；AP75 与固定定位诊断不相互矛盾 |
| 非目标类内容支持 | C1−C1_y 三 seed 全正且 mean>0；报告梯度剂量，措辞限定为加入该项的净增量 |
| 教师定位内容支持 | L1−L_GT 三 seed 全正且 mean>0；报告剂量、GT 辅助标签与选择继承边界 |

这只是建议的实施化规则，须由主计划在新 AP 前明确采用或替换；不是包内已经定义了这些最后两行。差值小于实际价值门可记方向性改善/不升级，不必二分为“有效/完全无效”。

## 5. 最高优先级缺口：不能遗漏四臂归因

工作区 AGENTS §4 明确要求 **paired / shuffled / same-modal / weight0(native)**，缺一不把增益送入论文。新规格 §9.4、§16 把后续同模态/内容控制写得较弱，且预算只报最多 12 次长训；若直接照此结束，会达不到用户的投稿完成标准。

四臂必须作为最终保留方法的独立必做阶段写回计划，但无需给所有失败候选做一整套。

- C0 的 random 只检验选样，不是 shuffled。
- C0-shuffled / C0-same-modal 不能替 C1 做内容归因；载体/损失改变后重新绑定该方法的目标与对照。
- C1_y 不是 same-modal；L_GT 也不是 same-modal。两者都仍继承跨模态对象/选择信息。
- 若 C0 是最终类别方法，可复用其满足协议的旧 paired/N/random 与现有 seed42 两个内容控制；其 shuffled/same-modal 的 seeds 0/123 仍需补齐。
- 若 L1 作为独立结果进入论文，它也需要对应方法的 shuffled 与有效 RGB-only 教师；不能只凭 L_GT 过关。
- 对照类别/定位教师不得等于参考 R，防止“教师必须比参考好”的门退化为零信号。先测非零有效蒸馏。
- 对象级置换与全图 shuffled 都可能合理，但要固定一个明确定义，不能把全图破坏空间后的劣化当作精确几何机制的独立证明。改变 null 身份需要新 ID。

预算应分层公开：

| 层次 | 最多新增长训数 | 备注 |
|---|---:|---|
| 独立效用 | 6 | C1×3、L1×3；L 阻塞时只有 C1×3 |
| 内容消融 | 6 | C1_y×3、L_GT×3，仅为有保留价值的分支做 |
| 保留 C1 的四臂补齐 | 6 | shuffled×3、same-modal×3；N/C1 已在上面 |
| 保留 L1 的四臂补齐 | 6 | shuffled×3、same-modal×3；N/L1 已在上面 |
| 若类别最终保留 C0 | 4（条件性） | 现有 C0 seed42 两控制有效时，只补各自 0/123 |

这些不是一次排队的承诺，也不是必定全部运行；它们说明“12”是核心比较上限，**若 C1/L1 两条都保留并独立主张跨模态价值，总新增可以达到 24，而非 12**。新 N 或第二数据集不在其中。为快出稿，可优先把一个最终保留分支的完整归因闭合，另一分支保留机制/负结果身份，避免同时扩两套未必有价值的大矩阵。

## 6. 资源与现实排期

11:19 快照为 3 张卡、5 个活动 lease，项目 RSS 约 141.33 GiB；全机无完全空卡。当时 C0-random 已接近 E200，C0-shuffled42 为 31/200、same-modal42 为 15/200。这只是历史快照，任何新任务仍必须动态查询。

保留 AGENTS 与现行 guard 中更严格的交集：通常 ≤3 张物理卡；满足占用后 ≥2 全空卡才可用第4张并落盘；每卡用户上限3而当前工程只准经实测双开；整卡 ≥2GiB 余量、项目显存 <70%；全部项目 RSS≤300GB，240GiB 预排队门继续用；所有 GPU probe/eval/train 共用 lease。

类别多通道本身不说明开销大或小。新 wrapper 是否重复计算无用 L、是否额外教师前向、区域池化实现都有影响，因此使用真实 24 次成功更新测量峰值和速度后再确定共驻数量。不要拿旧 C 的约 7.6GiB 直接授予 C1/L1 训练。

建议采用事件驱动排期而非保证 24–48 小时出齐：

1. **首个工作窗口：**材料/基线绑定、策略替换、C1/C1_y 内核与兼容性；CPU 几何审核可并行。
2. **资格通过后的首个可用 lease：**C1 校准与真实 canary，seed42 首发；其它固定 seed 随资源入队。已有 C0 两内容控制不抢停。
3. **首轮 C1 三 seed 完成：**同端点评估与伤害/修复诊断；按冻结规则决定 C1_y 和最终类别四臂补齐。
4. **L 独立准入时：**根据当时资源插入 L1；没有合格几何/信号就只交付阻塞清单，不让它阻塞类别归因。

单卡多开是允许的，不需要为了保守性人为退成“一卡一任务”；但也不能按“4卡×2任务”静态铺满共享服务器。队列交接需确认旧 worker 的完成、评估与 lease 责任，不只看进程退出。

## 7. 审阅建议的最终状态

**接受主线，修改完成条件后实施。**旧 N/C0 先绑定并通过新 wrapper 兼容验收；C1 作为独立候选先跑三 seed；L1 完成几何与信号准入才跑；C1_y/L_GT 按内容问题分别追加；最终保留方法的四臂三 seed 不可从计划中消失。新 seed-specific loader、密集特征、融合与全面基线重训均不顺带加入。
