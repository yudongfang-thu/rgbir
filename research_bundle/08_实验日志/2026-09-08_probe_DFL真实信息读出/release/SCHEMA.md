# Raw DFL producer schema

CLI: `run_dfl_probe.py --screen-release OLD_DIRECTION_RELEASE --reference-dir PINNED_RELEASE_GPU5 --config ORIGINAL_LLVIP_N.yaml --witness-release OLD_WITNESS_RELEASE --previous-probe OLD_WITNESS_PROBE --anchor-objects ACCEPTED_ANCHOR_JOIN_OBJECTS.jsonl --output NEW`.

`completion_receipt.json`: status=`RAW_DFL_SINGLE_BATCH_COMPLETED`, scope=`RAW_DFL_SINGLE_BATCH`, current_forward_id, dataset=llvip, seed42, batches1, frames32, objects_n80, actual raw_forward_counts student/reference/teacher each1, optimizer_updates/ema_updates/backward/training0, first_batch_stream_exact/identity_exact/student_full_state_unchanged/auxiliary_full_state_unchanged true, all_gradients_absent true, actual_amp, initialization path/bytes/mtime, resources + allocated/reserved peak MiB. historical_same_forward_claim=false. First32 contains31 nonemptyGT frames; frames32 retained in full identity.

`dfl_contract.json`: same scope/current_forward_id and initialization, previous_probe, objects_n80/frames32/unique_distributions, roles, decode per model, flags full_probability_vectors=true, GT_distances_clamped/cross_anchor_KL/new_NMS/new_matching/new_loss=false.

`objects.jsonl`: all80; stable_rgb_gt_id/stable_ir_gt_id, frame_id/image_index, bucket, rgb_gt_xyxy/ir_gt_xyxy, C_selected, historical_L2_gates with nulls unchanged, current_forward_id, roles={S,R,T}. S/R roles: historical_R_candidate, own_native_iou50. T roles: same_historical_R_index, same_S_native_iou50_index, same_R_native_iou50_index, own_native_iou50, historical_selected_T. Each is null if unavailable, else {distribution_id,anchor_index,own_gt_id,own_gt_xyxy,own_gt_modality,unclamped_gt_distance_bins[4],gt_distance_in_range_per_side[4],gt_distance_all_in_range}. T ownGT always IR, including same-index roles. One unique anchor can serve multiple GT roles without changing its distribution.

`anchor_distributions.jsonl`: deduplicated by model/image_index/anchor_index; distribution_id, current_forward_id, model, image_index, anchor_index/level/stride/row/col/center_xy, bins16, side_order=[left,top,right,bottom], raw_dtype, raw_logits[4][16], probabilities_fp32[4][16], probabilities_native[4][16], native_probability_dtype, expectation_fp32_bins[4], native_dfl_distances_bins[4], native_distance_dtype, box_fp32_xyxy[4], box_native_xyxy[4], native_decode_dtype, input_shape_HW, raw_feature_shapes, fp32_decode_exact/native_decode_exact true, new_forward=true. JSON conversion promotes FP16/BF16/FP32 scalar values without rounding to shortened decimals. No vectors truncated or renormalized.

FP32 probabilities come from the same full-tensor reshape/softmax axis used by original OEv1 decode. Native probabilities are actual inputs captured at pinned DFL.conv; native distances are its actual DFL output. The two representations and AMP rounding are separate. Both same-forward decoder closures are required; no cross-model/bin matching, KL, DFL loss or gradient is computed. Native `_inference(raw)` only decodes the same raw; it is not another backbone forward.

`first_batch_stream.json` and `identity_contract.json` exact to prior probe; `dependency_identity.json` contains required source/config/input stat, only own small producer sources are copied. No full-runtime duplication, hash, test access or training. Failure is `failure.json` after setup enters the protected block; outer queue captures earlier input rejection.

CPU commands: `python test_dfl_cpu.py --output NEW.json`; pinned installed runtime `python test_installed_native_cpu.py --reference-dir PINNED_RELEASE_GPU5 --output NEW.json` uses synthetic raw and actual native Detect/DFL decoding, no backbone/model checkpoint/GPU.

Pre-execution setup amendment: only this producer temporarily replaces native trainer.check_amp during _setup_train with the cfg AMP value, requiring exact equality to the accepted prior receipt.actual_amp; finally restores the original binding even on failure. This prevents an unrelated model download/forward in generic AMP setup. setup_amp records this bypass and explicitly denies full setup equivalence. The actual first-batch autocast remains unchanged. First-batch stream and complete identity equality are hard guards before the three measured forwards; mismatch fails, without selecting another batch. current_forward_id is exactly identical in completion, contract, every object and every unique distribution. head_decode_nonstate_caches_may_change=true distinguishes tensor state_dict equality from ordinary head anchor/stride cache attributes.
