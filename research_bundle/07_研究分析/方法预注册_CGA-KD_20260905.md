# 方法预注册：CGA-KD —— 条件感知几何锚定跨模态蒸馏

> 预注册日期：2026-09-05。**本文档在任何一个新方法臂读出结果之前冻结**；此后任何修改必须在"偏差记录"节登记并说明理由。
> 依据：P2 特征探针（`08_实验日志/2026-09-05_P2探针_DroneVehicle特征图`）、P3 昼夜分桶（`08_实验日志/2026-09-05_probe_DroneVehicle昼夜分桶`）、文献调研（`01_文献/RGB-IR_20260905新增/`）。

## 1. 假设与机制（What–Where–When）

- **H1（What-几何）**：RGB/IR 共享几何不变子空间；蒸馏定位分布（DFL）比蒸馏特征更抗负迁移（外观驱动的教师-学生冲突被构造性排除）。
- **H2（What-分解）**：跨模态不变/特异子空间的频段结构**随数据集变化**（实测：DroneVehicle 高/低频散度比 0.53–1.03，推翻 FreqKD 的普适 2.4×），因此不变子空间必须**逐数据集学习**；配对对抗验证（h 判别 paired/shuffled、g 不可判别）保证 g 不残留配对信息。
- **H3（When）**：教师可靠性随光照条件翻转（白天 RGB native +2.2 / 夜间 IR +11.2）；按 ISP 工作点估计 g(x) 逐样本调制蒸馏权重 λ(x) 可消除条件性负迁移。
- **层位（Where）**：特征级蒸馏只做 P4/P5（P3 架构饱和，实测 CKA 0.99）。

## 2. 冻结的实验设计

**数据集与协议**：DroneVehicle val（1,469 对）为开发/选择集（亮度中位数 78.283 分桶，阈值冻结）；test 封存至最终报告。学生 = RGB（yolo11n），教师 = IR（`infrared_seed42_native_b32a2`）。recipe 冻结 = adapted_v2 协议 yaml 全部超参（e200/b32/640/SGD lr0.01 lrf0.01/mosaic0/translate0.1/scale0.5/fliplr0.5/hsv0/erasing0/patience0/deterministic）。种子：筛选波 seed42；晋级臂补 0/123。

**臂矩阵（DroneVehicle，seed42 筛选波）**：

| 臂 | 内容 | 状态 |
|---|---|---|
| N | native weight0（同 recipe 无 KD，纯 ultralytics） | **本轮启动** |
| L | cmdistill_corrected（现有管线全量 KD，PCCFD/SLRD/IBCLD） | 已有（seed42 完成） |
| G | 几何锚定：DFL 分布蒸馏（P4/P5），无特征模仿 | 待实现 |
| I | 可学习不变分解 g/h + 仅蒸馏 g（配对对抗验证） | 待实现 |
| C | L 或 G/I 之上加 ISP 门控 λ(x)=σ(w·ĝ(x))，ĝ 由亮度/噪声统计初始化 | 待实现 |
| shuffled-G / shuffled-I | G/I 的打乱配对对照（归因必需） | G/I 晋级后 |

**预注册成功门（全部基于 val，读出前冻结）**：
1. 负迁移演示：L 相对 N 在 day 桶 mAP50-95 下降 ≥0.3 → 确认条件性负迁移存在（若不成立，H3 降级为观察）。
2. 组件门：G 或 I 在 full val mAP50-95 ≥ N +0.3 且 day 桶回退 <0.3。
3. 门控门：C 相对其基底在 night 桶提升 ≥+0.5 且 day 桶不劣于 N−0.3。
4. 论文主张门（最终）：完整方法（G/I+C）3 seeds 方向 3/3 且 full mAP50-95 ≥ L +0.5。
5. 归因门：G/I 的 shuffled 对照必须显著弱于 paired 版本（否则增益不归因于配对信息）。

**分析口径**：①逐亮度十分位 Δ-mAP 曲线（相对 N）；②主指标 mAP50-95（COCO）；③桶指标用冻结阈值；④所有对比报 mean±SD（最终波 3 seeds）。

**完整性**：①outcome-blind——臂配置在启动时登记，禁止读出后修改超参/损失；②deviation 登记节；③test 集只在 3 seeds 全部完成后评估一次；④V5 旧模型不进入本矩阵。
