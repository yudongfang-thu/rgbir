# 方法预注册：OS-SSL 红外域迁移测试（OS-SSL-IR，2026-09-06）

> 本文档在任何一个 SSL 臂的检测微调结果读出之前冻结。偏差须登记于文末。
> 动机：OS-SSL（paired BYOL 预训练）是全项目唯一 3/3 胜全部对照的正例（SpaceNet6 +3.3±0.9 AP50），但迁移 OGSOD/SiXiang 失败（+0.20/−0.45）。RGB-IR 是配对质量最好的域（同机密准配对），是否成立 genuinely 未知——本实验回答它。

## 1. 冻结的设计

**方法（冻结，照搬 SpaceNet6 yolo OS-SSL v2）**：
- SSL：BYOL（yolo11n 骨干 + 256/4096/256 projector/predictor，LARS），10,000 steps，patch 化配对图像（prepare_yolo_osssl_datasets.py --mode paired-tree，group-rule=identity）
- 三臂 manifest（build_yolo_osssl_manifest.py，shuffle seed=42）：`paired`（RGB-IR 正确配对）/ `shuffled`（错配 donor）/ `sar_only`（此处=IR-only 单模态 SSL）
- 注入：`inject_yolo_osssl_backbone.py` 严格注入 yolo11n 模板（init = `int8_cross_modal_stage2_v1/weights/yolo11n.pt`，与 cgkd_w1/L 完全同源，SHA 核对）
- **命名映射说明**：paired-tree 模式的 "sar" 槽 = DroneVehicle 红外图，"eo" 槽 = RGB 图（仅标签命名，方法不变）

**微调协议（适配数据集，冻结）**：DroneVehicle rgb.data.yaml，e200/b32/640/SGD lr0.01（= cgkd_w1 native 完全同 recipe），seeds 0/42/123，val 评估（eval_rgbt_detector，last.pt）。

**臂矩阵（12 个检测 run，其中 native 3 个已存在）**：

| 臂 | SSL 初始化 | 检测微调 |
|---|---|---|
| paired-SSL | paired manifest 10k 步 | ×3 seeds |
| shuffled-SSL | shuffled manifest 10k 步 | ×3 seeds |
| ir-only-SSL | IR-only manifest 10k 步 | ×3 seeds |
| native | 无 SSL（yolo11n.pt 直接注入模板） | **已存在**（cgkd_w1 三 seed，复用） |

## 2. 预注册成功门

1. **迁移门**：paired-SSL − native ≥ **+1.0 AP50** 且 3/3 seeds 方向为正 → "OS-SSL 在红外域成立"
2. **归因门**：paired − shuffled ≥ +0.5 AP50 且 paired − ir-only ≥ +0.5 AP50（跨模态配对信息与跨模态数据量各自有贡献）
3. **失败判读**：若 paired ≤ native，记录"配对质量足够好仍不迁移"，与 OGSOD/SiXiang 一起构成迁移边界图；任何情况下不得追加步数/改超参救结果
4. 全部对比报 mean±SD（3 seeds）与逐 seed 方向；test 不动

## 3. 预算与排程

SSL 3 臂（3 GPU 并行，~0.5-1h）→ 注入 → 微调 9 run（3 GPU × ~13h）→ 终局分析（`analyze_yolo_osssl_terminal.py` 配对 cluster bootstrap）。
