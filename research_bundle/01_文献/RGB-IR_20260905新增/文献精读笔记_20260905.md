## 深读 1 · FreqKD（arXiv 2026, 2606.11572）

- **一句话**：把 RGB→IR 特征蒸馏按空间频率解耦——低频带（形状/布局，跨模态一致）严格 MSE，高频带（纹理/细边，模态特异）0.1× 宽松 log-MSE，配 DINOv2 冻结教师 + LoRA 两阶段训练。
- **方法原理与实现**：
  - 教师=冻结 DINOv2 ViT-L(reg4)，学生同构 IR 版（热图复制 3 通道）；逐块蒸馏 blocks {7,15,19,21,23}
  - 特征逐通道中心化 L2 归一 → 2D FFT → 径向掩码 rc=0.50 分低/高频 → 低频 `||F_s^low - sg(F_t^low)||²`，高频 `log(1+||·||²)` ×0.1
  - Stage1：仅蒸馏目标 + LoRA r=64 训 12 epochs（不用检测标签）；Stage2：merge 后接 DINO-DETR 5 尺度检测头端到端微调
  - **谱散度分析**（500 对 KAIST 样本）：高频散度/低频散度 = 2.22–2.64×（所有层一致）→ rc 与 0.1 权重直接由测量决定，非手调
  - **CKA 诊断**：FreqKD 使低频 CKA 0.82→0.91、高频 CKA 0.13→0.02、全频 CKA 0.65→0.30 —— "整体更像教师反而变差任务，任务增益来自低频结构迁移"
  - **MMD 对照**：全局 MMD 的频带排序（0.74）与表征散度（2.42）不一致 → 全局匹配损失无法替代频段解耦
- **代码仓库**：摘要称 "Code is available here"，正文未给稳定 URL（arXiv 页面可能补充）
- **数据情况**：KAIST（cleaned instancesonly，9,466/967，Person 单类）；迁移 FLIR ADAS；跨任务 MFNet 分割
- **实验设置**：AdamW 5e-5，batch 2/GPU，12 epochs，DINO-DETR；**未见多 seed 描述**（单 run 叙述）
- **关键数字**（KAIST mAP50）：DINOv2 baseline 61.7；**Uniform feature KD 61.1（有害！）**；cosine KD 62.1；response KD 58.8（有害）；FreqKD **64.1**（+2.4）。消融：仅高频 MSE **−3.3**；仅低频 +0.9；两者组合 +2.4。rc 扫描 0.10/0.25/0.50/0.75 均 >baseline，峰值 0.50。FLIR 迁移 +2.1 mAP50（Car +0.7~Bicycle +4.2）
- **评价**：
  - 可信度：中上——消融链完整（band/cutoff/CKA/MMD 四层递进），但**单 seed、单数据集主表**；+2.4 的量级对单类检测尚可
  - 关键互证：**"uniform 特征 KD 有害"与我们 OGSOD H_F 换源有害（−0.0093）完全一致**；"高频不可跨模态"为 FreqMix 实验中 shuffled 高频注入≈无害提供了解释
  - 与我们的差异：它是"基础模型→IR"的表示迁移（LoRA，无检测器内 KD、无四臂归因）；我们是检测器内 paired KD + 定位蒸馏 + 路由，且数据集（航拍/遥感）不同——**不冲突，可引作频域先例并引用其谱分析方法**
  - 可借鉴：①频段解耦损失可作为我们特征蒸馏的组件；②frequency-resolved CKA 直接进我们的 P2 probe；③"整体 CKA 下降但任务提升"是回应审稿人"蒸馏后特征不像"的好话术

## 深读 2 · CGDet / CGCMKD（arXiv 2511.01435, 2025）

- **一句话**：训练期给热成像检测器加两个 RoI 级辅助损失——RoI 监督对比（RCS，类内聚/类间分）+ RGB 教师→学生 FPN 多层特征对齐（CMG），推理纯热成像零开销。
- **方法原理与实现**：
  - RCS：按 GT 框尺寸分配 FPN 层，RoIAlign 5×5 → GAP+线性投影得 embedding，监督对比损失（温度 τ）+ 大小 K 的 memory queue 供给难负样本
  - CMG：冻结的 RGB 预训练 backbone-neck 教师，在 P3/P4/P5 对齐：`L_cms = Σ_k ‖S_k−T_k‖₁ + β·Σ_k(1−cos(S_k,T_k))`
  - 总损失 `L = L_det(YOLOX) + λ_rcs·L_rcs + λ_cms·L_cms`（**λ 具体值论文未说明**）
  - ⚠️ 学生训练输入是 concat(热成像, Pearl-GAN 生成的伪可见光)——依赖 T2V 生成质量
- **代码仓库**：提取部分未给出 URL（标"未给"，待全文复查）
- **数据情况**：FLIR-aligned 5,142 对（4,129/1,013），3 类（person/bicycle/car）；FLIR-aligned 是手工校正配准后的社区版本（原始 FLIR 像素级未对齐）
- **实验设置**：YOLOX 系 + MobileNetV2 + 轻量 FPN，100 epochs，batch 4，单卡 A5000，SGD lr=1e-2；**未提多 seed**
- **关键数字**（FLIR-aligned）：CGDet mAP50 **82.8** / mAP75 47.2 / mAP 47.1；vs TIRDet 81.4（+1.4）；多光谱融合参考上限 IGT 85.0（V+T）
- **评价**：
  - 可信度：中——单 seed、单数据集、无 paired/shuffled 归因臂（对比全是"别的检测器"）；MobileNetV2 轻骨干上 +1.4 尚可信但幅度不大
  - 与我们重叠度最高：**"类别对比 + 特征对齐"这个组合已被占**。差异化必须靠：①DroneVehicle/VEDAI/LLVIP 三数据集（它只做 FLIR）②教师路由（它固定 RGB 教师）③四臂归因（它没有）④定位蒸馏（它没有）
  - 可借鉴：RoI 对比 + memory queue 的实现细节；"训练期辅助损失、推理零开销"的叙事框架

## 深读 3 · CMKD-Net（IEEE TCSVT 2026，XI et al.）

- **一句话**：多模态融合教师（LSKNet 双分支 RGB+IR）→ 单模态学生（RetinaNet/FCOS/ATSS/LSKNet）的**有向框**跨模态 KD，组件=多维特征蒸馏 MDFD（通道维+空间维，各 MSE+KL）+ 实例关系蒸馏 IIRD（RA-RoI Pooling + Gram 矩阵余弦）+ 新算子 RA-RoI Pooling（连续二重积分的有向 RoI 特征提取）。
- **方法原理与实现**：
  - MDFD-通道：特征空间压缩到 1×1×C → MSE（数值表征）+ KL（softmax 后分布）
  - MDFD-空间：通道压缩到 1×H×W → 同样 MSE+KL；施加在 4 个 backbone stage + FPN 同分辨率层
  - IIRD：GT 框内 RA-RoI Pooling 提取实例特征 → N×css 矩阵 → Gram 相似度矩阵 → 余弦损失
  - 蒸馏权重：弱学生（one-stage）配强教师 1:1:1；同构两阶段学生 λ1=1e-4, λ2=0.1, λ3=1
- **代码仓库**：提取部分未见 URL（标"未给"）
- **数据情况**：**VEDAI（OBB，10 折交叉验证）+ DroneVehicle（OBB，夜间为主）**——模态缺失场景（Cross-RGB / Cross-IR 两种学生）
- **实验设置**：教师 LSKNet-T（双分支融合）；学生四种；未提 seed 重复（VEDAI 靠 10 折控制方差）
- **关键数字**：
  - DroneVehicle（LSKNet 学生）：unimodal RGB 66.87 / IR 77.01 mAP → KD 后 **+0.23 / +0.45**（强学生上增益很小！）
  - 消融（FCOS 弱学生）：三模块全开 vs 仅单模态，cross-RGB **+2.88** / cross-IR **+3.65** mAP
  - VEDAI：Cross-RGB LSKNet 超过多模态教师（512 与 1024 分辨率均如此）
  - **关键观察（作者自己承认）**：DroneVehicle 夜间为主，IR 特征主导且互补，cross-IR 学生在 Freight car 上**超过多模态教师**
- **评价**：
  - 可信度：中上（TCSVT，消融成体系，10 折）；但 DroneVehicle 主表无 seed 重复、无 paired/shuffled 归因臂；**强学生上 +0.2~0.5 的增益说明"融合教师→强单模态学生"的天花板很低**
  - 可复现性：代码未给 + RA-RoI Pooling 自定义算子 → 复现成本高
  - 与我们的关系：**占掉了"融合教师→单模态学生 + VEDAI/DroneVehicle + 关系蒸馏"的坑**。我们必须差异化：①HBB 协议 + 多 seed + 四臂归因 ②教师路由（它固定融合教师；它自己的观察反而证明 IR 主导时该用 IR 教师）③DFL 定位级蒸馏（它是特征/关系级）
  - 对我们的直接启示：**别在强学生上比（涨不动）；要么用弱学生叙事，要么换增益来源（路由/定位）**

## 深读 4 · CCLKD（GIS 2026, Ma et al.）——我们的主复现基线

- **一句话**：easy 模态教师→hard 模态学生的三层次 KD（logit/feature/relation）+ 按类自适应温度（ATKD）+ 类别约束对比（CCL），YOLO 系骨干，三个基准（OGSOD-1.0 / DroneVehicle / VEDAI）。
- **方法原理与实现**：
  - **COP**（沿用 CoLD 的类别导向分区）：按教师预测的主导类别把候选框分为 target/non-target 组，逐类独立 KL
  - **ATKD**：对每个类别 j 用类内预测熵 Hj 自适应温度 Tj（熵高→温度高平滑去噪；熵低→锐化），施加于三层：LLD（logit KL）、FLD（候选框 bilinear k×k 网格特征对齐）、RLD（类内特征自相关矩阵 Frobenius 差）
  - **CCL**：正样本对=师生在 target 类候选框上的空间定位分布，负对=non-target，InfoNCE + 类平衡权重 wj
  - 学生总损失 = 标准检测损失 + λkd·ATKD + λcc·CCL
- **代码仓库**：提取部分未见 URL；**94 上 rgbt_cclkd_native_v1 是我们自己的复现实现**（kd_lld/kd_ccl 损失项与论文 LLD/CCL 对应）
- **数据情况**：
  - OGSOD-1.0：高分三号 C 波段 SAR 3m + Google Earth 光学 10m，256×256 patch，14,665/3,666，3 类（桥/港/油罐）
  - DroneVehicle：28,439 对（17,990/1,469/8,980），5 类车，**昼 14,478 / 黄昏 8,493 / 夜 5,468**
  - VEDAI：1,210 张 1024²、12.5cm、Utah 2012 春、RGB+NIR 四通道、9 类 3,640 实例
- **实验设置**：V100 单卡，SGD lr0.01/m0.937/wd5e-4，MixUp 增强；对比方法统一 YOLOv5 骨干，最强者再换 YOLOv11 复跑；**全文未见 seed 重复（单 run）**
- **任务方向（论文 Table 1 原文）**：OGSOD=Optical→SAR；**DroneVehicle=Infrared→（学生）**，理由"红外在低光/复杂天气的感知优势"；**VEDAI=Visible→Infrared**——与我们的实测（DroneVehicle IR 教师 +3.1）完全一致
- **评价**：
  - 可信度：中——协议描述完整、对比方法广（KD/DKD/CoLD/DetKDS/GKD/SSR-Net/CMDistill），但单 run、无 paired/shuffled 归因；"确保公平"的手段是让对比方法用各自推荐配置取最优，属尽力而为
  - **我们的复现（rgbt_cclkd_native_v1/v2）就是它的 RGB-T 实现**，v2 的 kd_pccfd/kd_slrd 是我们自己的改进组件——定位为"复现+扩展"而非新方法对照
  - 差异化空间：它 COP/ATKD/CCL 都是 logit/特征/关系级——**没有定位分布（DFL）级蒸馏、没有教师路由、没有四臂归因**。我们的方法在这三点上立差异即可

## 深读 5 · BoT-Multispectral（TPAMI 2025, arXiv 2411.18288）

- **一句话**：多光谱检测的"袋子技巧"系统研究 + 统一基准： backbone×检测器×融合模块×增强×对齐全要素扫描，**每个实验重复 20 次取平均**。
- **关键协议**：≤200 epochs + early stopping patience 20；KAIST 用 Miss Rate、FLIR/DroneVehicle 用 mAP；骨干 ResNet50 与 ViT-L；检测器 YOLOv5 与 Co-Detr。
- **主要发现**：像素级增强收益小（≤2.5%）且数据集敏感（≥3 个组合开始负迁移）；融合模块对骨干敏感（ResNet50 配 NIN、ViT-L 配 ICFE）；Fastmosaic 适合大数据集、Stitcher 适合复杂小数据集；夜间/低光用双通道同步增强。
- **代码仓库**：提取部分未见 URL（TPAMI 版可能随附）
- **评价**：**全领域唯一做重复统计的工作**（20 repeats）——直接反衬遥感应圈单 seed 的通病；它的协议表和指标约定是我们写对比表的模板；也证明"增强类技巧"天花板低，方法增益要靠结构/监督信号。
- **对我们的价值**：①对比表协议抄它的；②用它的 20-repeat 论据支撑我们"≥3 seeds"的最低线；③它没做蒸馏，无竞争冲突。

## 数据集协议速记（协议细节部分引自 CCLKD 与我们 94 侧审计）

### DroneVehicle（天津大学，arXiv 2003.02437 / Sun et al. 2022）
- 28,439 对 RGB-IR 无人机图像（17,990/1,469/8,980），5 类车（car/freight car/truck/bus/van），**昼 14,478 / 黄昏 8,493 / 夜 5,468**；OBB 标注 + 模态特异标注 + 遮挡/截断属性
- **协议注意**：①我们用 HBB 转换版（receipt 在 governance）；②标注模态间有差异（rgb label vs ir label），做跨模态 KD 时标签策略要冻结；③昼夜分桶评估是天然实验
- IR 教师强于 RGB（94 实测 0.816 vs 0.785；CMKD-Net 的 LSKNet 也是 IR 77.0 > RGB 66.9）

### LLVIP（arXiv 2108.10831）
- 15,488 对（12,025/3,463），单类 person，夜间为主；100% 配对；94 审计 edge-corr 中位 0.21-0.25
- **协议注意**：官方 test 无 val，须从 train 切 sequence-grouped dev split（防序列泄漏，94 governance 已有政策）

### VEDAI（JVCIR 2016, Razakarivony & Jurie）
- 1,210 张 1024²（12.5cm），9 类 3,640 实例，RGB+NIR；**官方协议 = 10-fold 交叉验证**；OBB（CMKD-Net 用 OBB+10 折；我们 94 侧是 CCLKD paper8 的 HBB 处理版）——论文里必须写清自己的协议变体
- 小目标（车辆 20-40px），配准好（同航拍平台），RGB 略强于 NIR（94 实测 0.646 vs 0.588）

### KAIST（Hwang CVPR 2016；我们拿到的是 Li et al. BMVC 2018 SDS 改进版）
- 95,428 对 640×512 行人；**评测用 Miss Rate（所有对数误检率）**，社区惯例忽略"遮阳板/unreasonable"帧；配准质量历史上受批评（"KAIST aligned"修正版存在）
- CCLKD/FreqKD 均用 cleaned instancesonly 变体（9,466/967）——协议碎片化严重，引用时必须注明变体

### M3FD（TarDAL CVPR 2022）
- 4,200 对 1024×768，6 类，含 Fusion/Detection 双任务标注；随 TarDAL 方法发布（申请制下载）
- 兼顾低光/白天场景；作为第三基准的可选

# 速读组（融合 SOTA 与素材库）

## 中等深度（方法机制 + 数字）

### C2F-RSDet（arXiv 2401.10731）
- 粗到细融合：冗余谱去除模块（频域动态滤波）+ 动态特征选择；三个 RGB-IR 数据集验证；**代码开源** github.com/Zhao-Tian-yi/RSDet。频域操作出现在融合侧（与 FreqKD 蒸馏侧呼应）。

### GSNDet（arXiv 2405.18955）
- GSMA 组洗牌多感受野注意力 + 多级路径聚合 neck；**提出 Multi-modal Supervision：双模态各自标注逐模态监督**（union 标注不公平——与我们的"模态特异标注审计"同问题意识！）；KAIST+DroneVehicle SOTA、效率优。

### ICAFusion（arXiv 2308.07504）
- 双向交叉注意力迭代融合（ICAF），轻量；**代码开源** github.com/chanchanchan97/ICAFusion；KAIST/LLVIP/FLIR/M3FD 多数据集 SOTA。

### SuperYOLO（TGRS 2023, arXiv 2209.13351）
- 超分辅助 + 像素级双向紧凑融合 + FCN 检测；航拍多模态小目标（VEDAI 系）精度-速度权衡标杆。

### ProbEn（CVPR 2022, arXiv 2104.02904）
- 概率集成 + 逐类 NMS/合并策略；**KAIST 昼/夜分开报 Miss Rate**；开源（GitHub）。蒸馏增益要和这个"免费集成"基线比才可信。

### CFT / C2Former（arXiv 2306.16175, IEEE TIM）
- 自适应特征采样 AFS（偏差网络预测跨模态偏移）+ 交互式交叉注意力 ICA；解决配准误差+融合不精确；KAIST/FLIR/LLVIP/M3FD。

### E2E-MFD（arXiv 2403.09323）
- 图像融合与检测端到端同步训练（粗到细）；**代码开源** github.com/icey-zhang/E2E-MFD；LLVIP/M3FD/MSRS 等。

### WD-FQDet（arXiv 2605.13621）
- **小波变换显式分解低/高频** + 频率感知 query 学习（backbone-share 范式）——频域在 RGB-IR 检测侧的又一例证（FreqKD 蒸馏侧、C2F 融合侧、此 query 侧）。

### YOLOv11-RGBT（arXiv 2506.14696）
- YOLOv11 单阶段多光谱框架；结论：**中层融合适合单阶段，P3 层中融合用更少参数更好**——支持我们 P3 定位蒸馏的层位选择。

### MORCNN（arXiv 2509.16957）
- 有向多光谱 R-CNN；**SMS 多尺度多模态训练策略 + CMLF 双模态标签融合规则**（缓解双模态标注不一致——又一个标注策略先例）。

### EarlyFusion-Rethink（arXiv 2405.16038）
- **核心论点：两分支结构不是必需，改进 early-fusion 可在保推理效率的同时逼近两分支**——对我们"部署成本"叙事有用：单模态蒸馏 vs 双分支的效率论证。

### MutDet（ECCV 2024, arXiv 2407.09920）
- 遥感 DETR 检测预训练：RGB-only 与多模态分支**互优化**（mutual pretraining）——"mutual 跨模态信号"思路的预训练版。

## 速读条目（素材库，各 1-2 行）

- **MODA**（arXiv 2512.09489）：航拍多光谱新基准（小目标+背景干扰），数据开源 github.com/shuaihao-han/MODA——第三数据集候选。
- **RemoteDet-Mamba**（2410.13532）：Siamese CNN 编码器 + 跨模态 Fusion Mamba，UAV 遥感。
- **IRDFusion**（2509.09085）：迭代关系图差分融合，抑制背景噪声；FLIR/LLVIP/M3FD SOTA。
- **ProtoHGF-Net**（2608.11595）：原型超图融合 + 模态内校准。
- **FoRA/LMA**（2407.16129）：**共享骨干 + 低秩模态适配器**（首例 shared-backbone+LoRA 多光谱检测）——与 FreqKD 的 LoRA 思路互证，轻量化叙事参考。
- **PedDet**（2502.14063）：行人多光谱自适应谱优化框架（面向所有检测器的优化框架）。
- **SCMF**（2606.30215）：稀疏跨模态融合，去重双分支冗余。
- **EGM-Det**（2608.11685）：**信息熵引导的门控融合**（场景自适应）——"按条件调模态权重"的融合版先例（我们的教师路由是 KD 版，需引用区分）。
- **YOLO-Multispectral-Survey**（2409.12977）：YOLO 系多光谱方法分类树与数据集清单——related work 骨架素材。
- **VLM-FewShot**（2512.15971）：VLM 少样本多光谱检测实证研究。

# 汇总：对我们方法设计的三条硬启示

1. **单模态推理 + 四臂归因是空白**：所有竞品（CCLKD/CGDet/CMKD-Net/FreqKD）都无 paired/shuffled/same-modal/weight0 归因——这是我们最稳固的差异化，也最便宜（只是多跑几组对照）。
2. **教师方向已是半公开秘密**：CCLKD 在 DroneVehicle 用 IR 教师、CMKD-Net 承认 cross-IR 学生可超融合教师、BoT 强调夜间同步增强——**"条件路由教师"是把分散的观察系统化**，需要引用这些证据并做成可学习/可配置的路由，而非固定规则。
3. **频域与标注一致性是两条暗线**：FreqKD（蒸馏）、C2F（融合）、WD-FQDet（query）、FreqMix（我们输入层）都在碰频率分解；GSNDet 的逐模态监督、MORCNN 的 CMLF 都在修标注不一致。我们的 paired/shuffled 归因恰好能回答"频域增益里哪部分是配对信息"——把两条线接起来。
