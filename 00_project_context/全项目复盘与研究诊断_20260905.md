## 1. 如何理解这次审计

这不是逐字审阅全部历史工程，也不是重新训练复现全部论文。本次沿着“入口 → 历史方法 → accepted 终态 → 当前源码与结果”定向核查了影响研究决策的主链，重点检查了结论能否由它引用的数字和实际代码推出。

证据分为三类，不能互相替代：

| 本报告标记 | 实際核验范围 | 边界 |
|---|---|---|
| A：本地已接受分析产物 | 读取逐 seed 表、JSON、COMMIT，关键 A8/A9 与 SX-APR 产物和 analyzer 保存哈希一致 | 没有重新打开所有 L20 原始数据、checkpoint、runtime；仍受原协议证据等级限制 |
| B：本轮远端原始小文件复核 | 94 的 results.csv、args、独立评估 JSON、源码、canary 日志；保存来源与 SHA256 | 描述性重算，不能自动升级为 accepted analyzer 或论文 claim |
| C：历史审计转述 | 较接近原始的历史审计、交接包、manifest | 只在记录的日期、配置和范围内成立；未访问的远端不视为已独立核验 |

本次 RGBT 结果快照收录 **89 个 results.csv 路径**，其中包含 native、teacher、正式臂、canary、未完成训练和失败尝试，绝不等于 89 次有效科学实验。方法目录 CSV 有 **65 行，其中 41 行标为 ARCHIVED_OR_NEEDS_AUDIT**，还混有控制、版本和基础设施；“尝试过多少方法”不能直接用目录数回答。

下文 AP/mAP 统一以 **0—100 的百分数**呈现；差值统一为 **百分点（pp）**。AP50、AP75、mAP50-95 分开，不将 precision 当作 AP。跨种子 SD 使用 sample SD；运行内最后十个 epoch 不是十个独立重复。

早期最有启发的对照是：旧 no-mosaic baseline 为 **55.654**，LADD 为 **57.662**，det-only reload 为 **57.982**。它说明原先归给新方法的变化并不能完整排除优化预算本身。另一组旧 direct400，seeds 0/1/2 的 plain 仅 **+0.305±0.605 pp**，singleproj **+0.682±0.738 pp**，都只有 2/3 正向。

## 3. 哪些结果真正值得相信

### 3.1 SAR 主线：存在 premise，但没有稳定自研方法

| 实验 | 指标与结果 | 能支持的判断 | 等级 |
|---|---|---|---|
| OGSOD exact400 baseline | RGB 58.756、SAR 48.825，教师优势约 9.93 mAP pp | 教师 detector 更强；不代表学生能获得同等提升 | C，历史正式 n=2 |
| OGSOD matched full CMD | 相对 H_S **−0.262±0.204 mAP pp**，seeds42/123；相对 shuffled 在 s42 为 +3.053 | 配对重要，但没有净胜强同模态对照 | C |
| OGSOD H_F source swap | direct50，**−0.932±0.066 mAP pp**，2/2 负 | 当前 feature 换源配置有害 | A/C，限定 direct50 |
| SiXiang full RGB-CMD A8/A9 | 相对 H_S **+1.051±0.900 mAP pp**；逐 seed **+1.367/+0.035/+1.750** | 跨模态 full bundle 有受限开发正信号 | A，exploratory pilot |
| 同一 A8/A9 paired attribution | paired−shuffle **+5.664±2.664**；paired−weight0 **+1.651±1.357 mAP pp** | 该设置依赖正确配对与非零辅助损失 | A；不是新方法 novelty |
| SX-APR B2+B2E | 21 格完整，六个预设门全部未通过 | 当前 residual/uncertainty 版本未成立 | A，REDESIGN |
| MM-ARCS SiXiang M1 | exploratory s0 +2.367；前瞻 s42 **−2.663**、s123 **+0.905 mAP pp** | 前瞻仅 1/2 过门；效果异质、不能筛掉负 seed | A，开发探索 |
| MM-ARCS OGSOD M0 | 已有物理训练，但 analyzer 完整性未闭环 | 无可报告最终算法效果 | A/C，证据工程失败 |

SX-APR 的失败尤其有解释力：P−H **+0.296±1.580**、P−shuffle1 **−0.007±0.566**、P−GT-only gate **−0.804±0.366 mAP pp**，后者三 seed 全负。因此，“跨模态 uncertainty gate 比简单前景选择更有用”没有获得支持。“六门失败”是联合裁决，不是六个均值都小于零。

代码还揭示 SX-APR residual 项实际上将学生拉向 SAR/RGB 混合 target；按 gate 区域均值归一化后，选中 10% 区域也不意味着全局 KD 剂量只剩 10%。这解释了为什么“残差化、局部化”的名称不能保证低冲突，但具体失败原因仍需因果实验确认。

OGSOD 的 50.478−50.867=−0.389 pp 与正式 paired delta −0.262 并不矛盾：前者是含历史 seed0 的三 seed 描述均值，后者只使用严格匹配的 seed42/123。不能把它们放在同一表中而省略样本集合差异。

A8/A9 的 3/3 正向也不是显著性证书：seed42 只有 +0.035 pp；A9 是替换两格工程失败，不是新增独立重复。它值得保留为方法动机，距离广泛、稳定的方法收益仍有距离。

### 3.2 SpaceNet6：预训练与监督蒸馏必须分开

这条线不应该被总结为“又一个失败”。

| 阶段 | 结果 | 正确解释 |
|---|---|---|
| 原论文 released/paper-faithful 复现 | baseline 46.20±0.80；AKD 45.17±0.93；OS-SSL 52.93±0.68；Full 52.60±0.79，均为 AP50 | baseline 与 OS-SSL 增益复现；released AKD 相对 baseline 三 seed 负，最终 Full 数值未复现 |
| YOLO OS-SSL v2 SpaceNet6 四臂三 seed | paired−native **+3.328±0.909 AP50 pp**；paired−SAR-only SSL **+3.771±1.231**，三 seed 胜全部对照 | 本项目较强的跨模态正面证据，属于预训练阶段 |
| 同一 OS-SSL 路径 OGSOD / SiXiang | 相对 native 分别 **+0.195±0.423 / −0.449±0.961 mAP pp** | 正效应不跨数据集普遍成立，不能将 SpaceNet6 结果直接推广 |
| 监督 P3 DFL 开发阶段 | 相对 native AP50/AP75/mAP 为 +0.69/+0.82/+0.58 pp | 开发集筛选结果 |
| 监督 P3 full-622 locked test | native 29.747±0.212、paired 29.864±0.904 mAP；Δ **+0.117**，逐 seed **−0.748/+0.664/+0.435** | 最终泛化增益小且有负 seed；AP50 均值基本持平（−0.003 pp） |

监督 P3 矩阵各臂已经共用 OS-SSL 初始化，因此后续 KD 边际收益弱，不会抹掉前一阶段 OS-SSL 的归因。相反，这提示“跨模态信息放在哪个训练阶段”可能比继续堆监督 KD 组件更重要。

原论文复现也有明确适用边界：公开材料的预处理与 SSL 配方不全，released 权重元数据与论文配置存在差异；AKD optical 离线特征与 SAR 随机翻转不同步是具体实现问题。因此未复现只能按已执行协议记录，不能推断所有实现均无效，更不能推断论文不实。

量化与部署链是可复用资产，但 QNN 图可编译不等于真实板端 AP/延迟验证；已有板端包仍标 not_run_on_board。把它写成已部署效果会超出证据。

### 3.3 FreqMix：原“SiXiang +9 AP”应停止引用

本轮直接核对 94 的 launch script、args、data YAML 和同 400ep 对照，发现历史总结跨错了数据集：FreqMix 实际是 **OGSOD，256px，E400，B64，SGD lr0.005，mosaic0**，不是总结表中对照的 SiXiang SAR300。

| OGSOD，同主要训练 recipe | seed42 mAP | seed123 mAP | 均值 |
|---|---:|---:|---:|
| native | 50.226 | 50.661 | 50.444 |
| H_S | 51.279 | 51.042 | 51.161 |
| FreqMix gray donor | 47.893 | 47.752 | 47.823 |
| FreqMix SAR donor | 47.939 | 47.692 | 47.816 |

因此，匹配数据集和主要 recipe 后，gray/SAR 版本相对 native 约 **−2.62/−2.63 mAP pp**，相对 H_S 约 **−3.34 mAP pp**。这是本轮最重要的原始证据纠错之一：原来的 +9 既不能作跨模态收益，也不能作已经成立的自模态增强收益。

另外，所谓 SAR-self donor 虽来自 shuffled SAR 高频，其幅度 RMS 校准仍使用 shuffled gray 信息，因此严格说它也不是完全不访问 optical 的纯 SAR null。将来若做输入增强研究，需要另立纯 SAR 对照。以上为两 seed 的原始文件复算，不替代 accepted analyzer，也未重新验证全部 checkpoint 链。

## 4. 当前 RGB-T 线：原始结果比汇总叙事克制得多

## 5. 近期探针与 CGA-KD 有哪些必须先纠正的问题

### 5.1 P2 对照模型身份错误，足以污染“蒸馏拉力”结论

P2 实際加载 `rgbt_cmdistill_paper_reconstructed_v2/native_rgb_s42_b64_e200/weights/best.pt`。94 的该 run `args.yaml` 明确指向 **VEDAI512_paper8_hbb_official_fold01**，而 distilled 模型训练于 DroneVehicle。后续 P3 昼夜日志也已承认同名 checkpoint 的误用。

因此 CKA 0.560→0.883 不是干净的“同数据/同 recipe native 经 KD 后改变”，混入数据集、训练配方与任务身份。P2 summary 只保存 teacher 路径，没有保存两个 student 的身份，降低了自包含可追溯性。P3 的 summary 已修正，但本地保存的 P3 脚本仍指向旧 VEDAI 路径，按它重跑会重现错误版本。

### 5.2 所谓 linear CKA 实际没有中心化

`linear_cka(x,y)` 直接计算 `||xᵀy||²/(||xᵀx||·||yᵀy||)`；调用前也未沿样本轴去均值。此处是未中心化对齐，不能直接称标准 centered kernel alignment。共同激活均值、背景结构等可能抬高数值，因而 P3≈0.99 不足以证明“架构饱和”或“P3 没有蒸馏空间”。标准 CKA 的中心化定义见 [Kornblith 等原论文](https://proceedings.mlr.press/v97/kornblith19a/kornblith19a.pdf)。

而且即便正确计算 CKA，表征相似也不等于任务冗余；相似度低也不证明更值得蒸馏。该探针使用单张图内空间位置为样本，不能直接替代跨图/实例级可迁移性评估。

其他边界：shuffled 实际是文件序列反转，只有一个固定 null；same-input 把 IR 教师喂 RGB，是教师分布外输入，不能据此把训练差异与模态差异因果分离；FFT 比值按整个平面均值而非频带元素数归一，且对未证明通道对应的独立模型逐通道相减。该比值尚不能“推翻另一篇论文的普适 2.4×”，更不能直接决定方法频段权重。

### 5.3 亮度桶支持条件差异，不支持“必然负迁移”

修正后的摘要显示：高亮桶 RGB−IR 为 **+2.229 AP50 pp**；低亮桶 IR−RGB 为 **+11.248 AP50 pp**。这是一条值得验证的条件差异观察。

但 day/night 是按验证集亮度中位数划分的高低亮代理，并非官方光照标注；teacher/student 分别用各模态自己的标签评估，尚未在同一可见目标集合/坐标系上量化错误互补。不同模型与标签下的 AP 优劣，也不自动推出辅助损失对学生的因果伤害。当前 distilled/native recipe 又不一致，因此“固定教师必然在一侧负迁移”过强。

建议保留阈值冻结和分桶描述，将机制假设改为“条件与教师相对效用可能有关”，待匹配 N/L 的分桶差值、共同目标错误分析和门控消融验证。夜间 IR 看到而 RGB 几乎没有观测的目标，即使教师更强，也可能恰恰最难让 RGB-only 学生学会。

### 5.4 CGA 的预注册定义与当前运行源码不相符

本轮读取了 94 `artifacts/cgkd_20260905/train_cga_kd.py` 的当时快照：

| 臂 | 预注册声称 | 实际代码与证据 | 后果 |
|---|---|---|---|
| G / geom | P4/P5 的 DFL 分布蒸馏，无特征项 | `kd=terms.iou+terms.cls`；DFL 只用于解码期望框，没有分布匹配损失，也没有只筛 P4/P5 | 即便跑完，也不能用于验证注册的 H1 |
| C / gated | 用样本可靠性调制 KD 权重，可学习 gate | 固定 sigmoid 乘 teacher feature；PCC 与 cosine affinity 对正标量尺度不变，boxes/scores 保持原样 | 非退化条件下损失在代数上与 L 等价（数值误差/epsilon 附近除外）；并未实施预想的门控 |
| I / invariant | g/h 可学习分解，分别具有预期不变/特异性 | 共用按 P4=128 初始化的投影却应用到 P5=256；canary 已报通道不匹配 | 已发生工程失败，不能读成科学失败 |
| I，后续风险 | g/h 和 discriminator 能被优化 | aux 在首个 KD forward 才 add_module，当前 trainer 更早建立 optimizer；无 add_param_group | 修通通道后仍有新增参数漏进优化器的静态证据，需参数 ID/梯度更新检查 |
| I，目标定义 | h 能识别 pairing，g 不能 | h 同样用了 GRL；g 又反转标签，共享 discriminator 目标冲突；student embedding 也接判别梯度 | 不能声称当前目标实现了预注册的语义分解 |

DFL 指边界框离散分布本身的学习；仅将分布解码成期望框再做 IoU/BCE，不等价于蒸馏该分布。[GFL 原论文](https://arxiv.org/abs/2006.04388)。C 的正确实现应在未归约的每样本/每位置损失上乘 gate，再按预设归一化求和，并与恒定同均值剂量、随机或打乱 gate 对照；这属于后续修订建议，本轮未修改训练。

更基础的概念问题是：**模态不可判别不等于配对不可判别**。两模态共同的目标位置、类别和实例结构，往往正是区分 paired/shuffled 的信息。强迫保留的 g 完全不能区分 pairing，可能消除本来要传递的共同信息。正交约束和判别器接近随机本身也不能证明共享/私有语义被识别。

当前预注册还缺明确的 same-modal 最终臂、G/I 参数剂量、C 基底选择规则、shuffled 显著弱于 paired 的检验定义、checkpoint/EMA 端点及 gate 预算对照。文中“+0.3/+0.5”应明确是 pp，而非 0—1 AP 数值。修订应保留原版、登记版本和偏差，不能在原文件里无记录地改写。

## 6. 为什么长期方法多、增益少

**第一，真正的目标尚未一直保持一致。** 原始目标是 RGB→SAR 的部署期 SAR-only 检测；目前又加入 IR→RGB、融合教师、OS-SSL、频域输入增强和量化部署。这些问题都有价值，但 teacher、学生输入、任务目标和可用信息不同，不能让某条线的正例替另一条线提供未经验证的动机。每轮应先固定部署时到底能看到什么、要弥补哪一种可观察的错误。

**第二，教师强于学生只是起点。** 在固定教师 target、平方拟合误差和总体分布的简化条件下：

`E||s(Xs)−T||² = E||s(Xs)−E[T|Xs]||² + E||T−E[T|Xs]||²`。

第二项代表学生输入条件下仍无法解释的教师变化。教师独有的光学纹理或夜间热目标能提升教师，却未必能从 SAR/RGB-only 输入恢复。KD 可以改善表示、样本效率与优化，但 teacher gap 不是可兑现的学生上限。这个分解是理解问题的理论框架，不是对项目 irreducible fraction 的实测估计。

**第三，辅助目标更容易改善 proxy，而不是最终检测。** 从 TSKD 的可达性、RIF 的 oracle、TCPAD 的可预测性，到 P2 的 CKA、CGA 的分解，反复出现“中间量变好 → 方法应有效”的跨越。项目已多次看到 oracle signal 有而下游 projector/task gate 无、paired>shuffle 而输 H_S。以后每个 probe 应只回答它实际检验的问题。

**第四，真实效应小，足以被 recipe 和评估身份压过。** reload、schedule、BN、初始化、模态标签、不同数据集 checkpoint、best/last、precision/AP 等差异都曾参与结论。对于 +0.1～0.5 pp 的效果，这些不是次要工程细节。先检查方法身份和匹配条件，比增加复杂 loss 更可能避免无效计算。

**第五，方法复杂度增长快于因果证据。** 不变分解、门控、几何、对抗约束同时进入一个方法，一次成败难以解释。当前 C 的代数恒等与 I 的通道错误说明，仅 canary 能启动或 receipt 能生成，不代表科学干预已经实施。需要以真实 tensor/参数更新证明“开关真的改变了预期机制”。

**第六，文档传播正在制造二次误判。** 最近同一天的新汇总也能出现错数据集、错指标和旧终态。部分 README/总表还停在 SX-APR pending、MM 全部未分析；另一些 FINAL 文档有互相矛盾的日期和估算结果。新会话再根据这些总结设计方法，就会重启已经失败的分支，或者围绕不存在的 +9 AP 优势做研究。

这些问题不能全部归结为“数据不适合”。SpaceNet6 OS-SSL 与 SiXiang full CMD 的正例说明有可用信号；也不能全部归结为“代码有 bug”，因为修正协议后的 SX-APR、MM 前瞻和 P3 locked test 仍有真实科学负结果。

## 7. 建议怎样收敛后续工作

建议下一阶段只保留 **一条主要检测任务、一种最小蒸馏干预和一组足够强的控制**，按以下依赖关系推进。

| 优先级 | 具体工作 | 完成标准与用途 |
|---|---|---|
| P0：证据纠错 | 把 FreqMix 数据集/对照错误、HNEWA precision 误引、P2 checkpoint/CKA问题、SX-APR/MM终态更正加入统一证据入口 | 后续方法动机不再引用已知错结论；保留历史原件和勘误链 |
| P0：当前基准闭合 | 收齐已启动的 CGA native 三 seed，以同 evaluation/last-or-EMA 规则评 N/L；核对 loader/RNG/初始化/更新数 | 先得到可信“是否有负迁移及在哪些桶”答案；禁止用中途值下结论 |
| P0：实现契约 | G 做真正的分布损失；C 直接加权 unreduced loss；I 先修通道/optimizer与目标定义，再决定是否保留 | 合成可控例子与短步数确认开关、梯度和剂量真实改变；不以长训替代功能核验 |
| P1：现有结果补归因 | 补齐 HNEWA seed42 native 身份与 final 端点，再核对 paired/same-modal/shuffle/null；统一教师预算 | 明确小增益是否真实净增益，不预先承诺有效 |
| P1：定位可用错误 | 在冻结的开发数据上做共同目标的类别/定位/漏检分解；分辨 teacher 更准、student 有观测、两者几何可对应的区域 | 以可用的错误互补定义最小干预，避免只按亮度或相似度调权 |
| P1：最小四臂 | 对简单候选执行 native/weight0、same-modal、paired、shuffled；门控额外加同平均剂量随机 gate；几何共享变换 | 三 seed paired 同时胜强 baseline 与关键归因控制，才能继续加组件 |
| P2：泛化 | 前述开发门通过后冻结方法，在预先选择的第二数据集与封存 test 检验 | 方法选择和最终验证分开；失败如实终结版本，不回头改阈值救结果 |

具体取舍建议：

- **保留 DroneVehicle 作为当前开发场景**：已有三 seed 模型、配对与控制，不应因为误差分析不完善再开七个数据集。先验证同一 RGB 任务上教师给出的几何知识是否真的可用。
- **LLVIP 适合作为预先固定的外部开发验证**，但现有 h1 的 seed42 负方向说明它不是已经成功的主表。继续遵守 grouped fit/dev 与 test 封存。
- **SiXiang 保留 full-CMD premise 与强 H_S 对照**；SX-APR、MM-ARCS SiXiang portability 当前版本应按已判决状态关闭；OGSOD M0 保留 analyzer 完整性阻塞状态。FreqMix 不能作为已证明的 +9 强基线。
- **OGSOD 主要承担历史对照与困难场景分析**。由于 test 已多次用于开发，不宜作为新方法独立泛化的唯一证据；也不应笼统宣布“所有特征 KD 在 OGSOD 判死”。
- **SpaceNet6 保留 OS-SSL 正例与成熟复现/部署工程**。若研究范围允许包含预训练，它是值得重新聚焦的可靠资产；若论文只讲监督 KD，需明确它仅作为共同初始化和相关证据。
- **暂缓给 VEDAI/M4-SAR 等新数据集排列“潜力星级”并据此大规模开跑**。数据配对好、teacher gap 大只是候选条件，原始协议与教师身份还要先统一。
- **降低 I 复杂分解臂优先级**。当前动机、识别目标和实现同时有问题，继续扩充此臂的信息收益低于把简单几何项和 matched baseline 做扎实。

这些是后续行动建议，本次没有执行新训练或修改已有预注册。若后续训练采用新版本，继续遵守 94 最多三张 GPU、每卡最多三任务、实测峰值后留至少 2GB、总内存不超过 300GB，并将每个实验独立登记。

## 8. 论文目前能讲什么

现阶段还不足以写成“提出新颖分解/门控蒸馏方法，在多数据集稳定优于强基线”的主方法稿。缺口包括净效用、机制归因、跨 seed 方向、独立泛化和实现身份，补若干消融图无法弥补这些缺口。

目前有价值的研究认识是：

1. 跨模态信号确实存在，但能否利用高度依赖数据集与训练阶段；SpaceNet6 OS-SSL 是明确正例。
2. 教师性能优势、paired 比 shuffled 好、表征相似度上升，分别回答不同问题，任何一项都不自动推出学生优于强同模态对照。
3. 多个复杂监督 KD 候选在干净控制或 locked test 上没有兑现开发收益；这为后续更窄的研究问题提供了证据基础。

如果以方法论文为目标，最值得争取的是一个**机制简单、代码与数学一致、净增益清楚、归因完整、独立测试保住**的小结果。若经过有限且预先冻结的最小实验仍无稳定收益，再考虑以系统复现/证据分析为中心重构研究贡献；当前不能预先承诺任何投稿方向会被接受。
